# 06 · 宫殿：复古像素 JRPG

> **参考坐标**：最终幻想 1 的结构（大地图 / 城镇 / 迷宫 / 随机遇敌 / 四人队 / 指令回合）
> ＋ 八方旅人的战斗（护盾 Break / BP 增幅 / 弱点连打）。
> **本文件是夜间玩法的主设计**，并明确它和 `06-塔防行间.md`、`07-序章与哈莉线.md` 的关系。

---

## 0. 一句话

**白天的霍格沃茨是日程表，夜里的宫殿是一款能真的玩的 8-bit JRPG。**

四名角色、回合指令、随机遇敌、破防连打、宝箱与 Boss。打完之后回到现实——她变了，还是没变。

## 1. 与现有文档的关系（先理清，免得打架）

| 文档 | 状态 | 说明 |
|---|---|---|
| `07-序章与哈莉线.md` | **canon，最高优先** | 主角固定为**男版哈利**；哈莉＝平行世界的女孩；新增 `/秘密` 与「发现度」 |
| 本文件 | **主玩法** | 宫殿＝像素 JRPG，取代旧「行间节点图」 |
| `06-塔防行间.md` | **保留为子玩法** | 塔防改作宫殿里的「守门」房型，默认关闭，可整座宫殿不启用 |
| `06-宫殿像素游戏.md` | **作废** | 早期潜行版草稿，只留作参考 |

**为什么以 JRPG 为主**：塔防一局 15–20 分钟、只能守不能走；JRPG 有探索、有成长、有宝箱、有地图记忆，更像「进入一个人的心」。
**为什么保留塔防**：它已经设计完整，作为 Boss 前的「守门战」房型可以复用，且给不想打回合制的玩家第二条路。

## 2. 为什么是 JRPG

| 维度 | 节点图（旧） | 塔防 | **JRPG（本方案）** |
|---|---|---|---|
| 操作 | 选路 | 摆塔 | **走迷宫 + 打回合制** |
| 成长 | 无 | 局内 build | **等级 / 装备 / 技能，跨局累积** |
| 情绪 | 抽卡 | 布防 | **探索 + 养成 + 打赢** |
| 与七学年 | 弱 | 中 | **强：等级正好铺满七学年** |
| 内容成本 | 每座重写 | 每座重写 | **换敌人表 / 换配色 / 换 Boss 即可** |

FF1 的「走迷宫 → 遇敌 → 回城补给 → 变强 → 再往下」循环，天然适配一张七学年的长线卡。

## 6. 属性与成长

| 属性 | 作用 |
|---|---|
| HP / MP | 生命 / 施法资源 |
| ATK / DEF | 物理攻防 |
| MAG / RES | 魔法攻防 |
| SPD | 行动顺序、逃跑 |
| LUK | 暴击、掉落、偷窃 |

**等级 1–20**（宫殿内独立，不与五维换算）：
`下一级经验 = round(10 × 等级^1.5)`，满级累计约 **4,100**。
普通战斗 8–40 exp，Boss 120–300；三座大宫殿 + 若干小宫殿可到 20 级。

## 7. 战斗

### 7.1 回合流程

```
① 回合开始：状态结算，全员 BP +1（上限 5）
② 按 SPD 排序
③ 玩家角色行动：攻击 / 魔法 / 道具 / 防御 / 逃跑
④ 结算：伤害 → 弱点 → 护盾 → Break → 1 More
⑤ 敌人行动（按 AI 表）
⑥ 回合结束：Break 恢复、状态倒计时
```

### 7.2 伤害

```
物理 = max(1, floor((ATK×2 − DEF) × 属性倍率 × 浮动 × 暴击 × Break))
魔法 = max(1, floor((MAG×2 − RES) × 属性倍率 × 浮动 × 暴击 × Break))
浮动 0.9–1.1；暴击 5%（LUK 每 10 点 +1%）×1.5
Break：受伤 ×1.5，DEF/RES 视为 0
防御：×0.5，下回合先手
```

**七属性**：火 / 冰 / 雷 / 风 / 光 / 暗 / 物理。倍率：弱点 1.5、普通 1.0、抗性 0.5、免疫 0。

### 7.3 护盾与 Break（八方）

- 敌人护盾 **◆1–5**，只有命中弱点才削 1。
- 归零 → **Break**：本回合剩余 + 下一回合无法行动，受伤 ×1.5，DEF/RES = 0。
- **合围**：全场敌人同时 Break → 全队免费全体攻击 + 必掉宝箱。

### 7.4 BP 增幅

BP 上限 5，每回合 +1，Boss 战开局 3。

| 投入 | 效果 |
|---:|---|
| 1 | 伤害 ×1.5 |
| 2 | ×2.0 或多 1 段 |
| 3 | ×2.5 或多 2 段 / 全体化 |

### 7.5 1 More

命中弱点 → 该角色立刻再行动一次（每回合每人 1 次）。

### 7.6 状态异常

中毒（3 回合 −5%）、麻痹（1 回合跳过）、沉默（2 回合不能施法）、恐惧（ATK/MAG −30%）、护盾（受伤 ×0.7）、加速（SPD ×1.5）。Boss 免疫麻痹与沉默。

### 7.7 全灭

全员战斗不能 → 撤退：碎片全失，体力 −20，伤势 +20。**不写游戏结束。**

## 8. 地图

### 8.1 三类场景

| 场景 | 屏数 | 作用 |
|---|---:|---|
| 霍格沃茨 | 4 | 礼堂 / 走廊 / 庭院 / 图书馆，通往宫殿入口 |
| 霍格莫德 | 2 | 商店 / 旅馆 / 三把扫帚 |
| 宫殿 | 3–5 层 | 迷宫 + 遇敌 + Boss |

现实层主体仍是文字与日程；像素场景只服务宫殿与短途探索。

### 8.2 迷宫

- 每层 24 × 18 tile。
- **随机遇敌**：步数阈值 10–18，之后每步 12%。
- 宝箱 2–4 个/层；门需要钥匙；楼梯 1 个/层。
- **安全屋**：存档 + 半恢复 + 换队伍。
- **认知商店**：部分层出现。
- **陷阱**：扣血或触发遇敌。

### 8.3 遇敌组

| 层 | 示例 |
|---:|---|
| 1 | A×2 / A + B |
| 2 | A×2 + C / B×2 |
| 3 | A×3 / D + B×2 |
| 4 | D + C×2 / E |
| 5 | Boss + 随从×2 |

### 8.4 Boss

每座宫殿一个 Boss（宫殿主的影子），三阶段：
100–60% / 60–30% / 30–0%，每阶段换弱点与护盾（3→4→5）。
阶段切换**暂停战斗**，交给模型写对峙戏。击败 = 秘宝到手 = 改心。

### 8.5 守门战（塔防子玩法，可选）

Boss 前可有一座「守门」房，用 `06-塔防行间.md` 的规则：

| 项 | 值 |
|---|---|
| 战场 | 3 路 × 6 列，12 个可部署格 |
| 波次 | 3 波（比塔防版少 2 波） |
| 单位 | 队伍 3 人各算一个单位（射程/阻挡按职业定） |
| 资源 | 意志，初始 6，每波 +3 |
| 失败 | 不判死，警戒 +25 |

**默认关闭**。开启时每座宫殿一次，赢给一件稀有碎片，输掉不影响通关。

## 10. 与现实系统的接口

| 现实系统 | 宫殿侧 | 写法 |
|---|---|---|
| 行动点 | 潜入 2 点 | 进宫殿前扣 |
| 期限 | 每座大宫殿一个截止 | 逾期＝宫殿永久关闭 |
| 社群 Rank | 决定能否入队 | 读 `/关系/{键}/Rank` |
| 塔罗被动 | 队伍被动 | Rank 5 解锁 |
| 五维 | 只给起始加成（胆识每阶全队 HP +2） | 进宫殿时算一次 |
| 体力 | 出宫殿按 HP% 折算 | 写回 `/主角/体力` |
| 秘密/发现度 | 哈莉随队外出 → 发现度 +5 | 读 `/秘密` |
| 检定脚本 | 宫殿外检定 | 宫殿内由前端结算 |
| 模型 | 层间叙事、Boss 三阶段、改心 | 摘要注入 |

### 10.1 摘要格式

```
[宫殿] 马尔福庄园 2F · 遇敌 3 · 消耗 HP42/MP18 · 取得钥匙×1 · 警戒 36
[战斗] 认知存在×2 · 3 回合 · 破防 1 次 · 无伤
[改心] 德拉科娅·马尔福 · 秘宝「家族纹章原版」 · Rank 5 → 6
```

模型据此写 2–4 段，**不写坐标与具体伤害数字**。

## 13. 技术

```
iframe（无沙盒）
 ├─ canvas 320×180，整数缩放
 ├─ 场景栈 Field → Battle → Menu
 ├─ RNG(种子) / 地图生成 / 敌表 / 技能表 / 道具表
 ├─ 存档 localStorage + MVU
 └─ 输入 键盘 + 触屏

MVU /宫殿
 ├─ 队伍[]（等级、HP、MP、装备、BP）
 ├─ 场景 / 地图（种子、层、坐标、开箱）
 ├─ 遇敌计数
 └─ 战斗调试态（可选）
```

- **精灵**：8 职业 × 4 方向 × 3 帧 = 96 帧（16×16 像素数组），敌人 24 种（32/48 px）。
- **字体**：方案 A 系统字体（零成本）／方案 B 点阵子集（20 KB）。
- **音乐**：WebAudio 方波，4 首循环，默认 30% 音量。
- **降级**：无 canvas → ASCII 地图 + 指令；不想玩 → 「自动探索」按概率结算，只出摘要。

## 16. 收束

**宫殿不是副本，是她的心。**

你在里面走、打、翻箱倒柜，最后拿到的那件东西，是她最不想让人看见的。
打完之后回到现实，她还坐在原来的位置——但你们之间多了一件只有你知道的事。

这就是为什么它值得做成一个小游戏，而不是一段文字。
