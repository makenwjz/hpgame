## 1. 八个工作包

### W1 · 状态栏与创角页（最急，因为玩家第一眼就看它）

**做什么**：6 页状态栏 + 1 张三栏创角页，全部走正则注入的 HTML。

| 页 | 内容 |
|---|---|
| 主角 | 姓名/学院/年级/血统/魔杖/声望阶 + 体力·魔力·伤势三条 + 加隆 |
| 五维 | 五条五段进度条（阶 + 经验 x/6） |
| 日程 | 本周 x/4、本周安排、下一期限倒计时 |
| 关系 | 分层 roster：T1 展开 / T2 简表 / T3 名单 |
| 网 | 22 节点 + 边（实线公开 / 虚线圈内 / 点线隐秘） |
| 宫殿 | 层/灯火/警戒/意志/残留；不在宫殿时整页隐藏 |

**怎么做**
1. 写 `src/ui/status.html`（纯静态骨架 + `{{占位}}`）
2. 写 `src/ui/status.js`（读 MVU → 填 DOM；每 500ms 节流刷新）
3. 写 `tools/build-regex.mjs`：把 HTML+JS 压成一条正则的 `replaceString`
4. 正则匹配正文里的 `<content>`，替换成「正文 + 状态栏」

**产物**：`dist/regex/01-status.json`、`dist/regex/02-create.json`
**验收**：手工构造一段 `<content>` 文本，跑 `node tools/render-regex.mjs` 输出 HTML，浏览器打开能看到六页并正确显示假数据。
**依赖**：无。**现在就能做。**

### W2 · 卡 PNG 打包（让你能真的导进去看）

**做什么**：把 `dist/card.json` 塞进 PNG 的 `tEXt` 块（key = `chara`），生成可导入的卡图。

**怎么做**
1. `tools/pack-png.mjs`：读一张底图 PNG → 解析 chunk → 插入/替换 `tEXt`(chara) 与 `tEXt`(ccv3) → 重算 CRC → 写出
2. 底图先用 400×600 纯色占位（美术后补）
3. 同时导出 `dist/card.json` 供"导入 JSON"路径使用

**产物**：`dist/card.png`、`dist/card.json`
**验收**：`node tools/verify-png.mjs` 能读回 JSON 且与源一致（字节级比对）。
**依赖**：无。**现在就能做。**

### W3 · 宫殿前端 MVP（能走 + 能打）

**做什么**：`320×180` 像素房间，能走、能开箱、能触发一场带 Break 的战斗。

**怎么做（按 `15` 的四步）**
1. **能走**：canvas + 瓦片碰撞 + 走格移动 + 虚拟方向键（3 天）
2. **能打**：战斗场景 + BP + 护盾 + Break + 1 个敌人（5 天）
3. **能通关**：斯内普宫殿 2 层 + 3 敌 + 1 Boss 两阶段 + 改心判定（6 天）
4. **能铺**：9 套调色板 + 数据表（10–15 天）

**技术要点**
- 单文件 HTML（构建时内联），≤450KB
- 文字全走 DOM，canvas 只画图
- 前端只发意图，数值走 `core.mjs` 的 `resolve()`；战斗结果由脚本写回

**产物**：`src/palace/index.html`、`src/palace/engine/*.js`、`dist/palace.html`
**验收**：浏览器直接打开 `dist/palace.html` 能走完一层、打出一次 Break。
**依赖**：无（可离线开发）。**现在就能做。**

### W4 · 正则与前端接线（把 W1/W3 挂进卡）

**做什么**：4 条正则（正文美化+状态栏 / 创角页 / 变量块隐藏 / 剥离自写 check）+ 宫殿 iframe 挂载。

**怎么做**
1. `tools/build-regex.mjs` 统一产出正则 JSON
2. 正则写进 `card.json` 的 `extensions.regex_scripts`
3. 宫殿入口：正文里出现 `<palace/>` 时，正则替换成 iframe（或酒馆助手前端目录）

**产物**：`dist/regex/*.json` 并入 `card.json`
**验收**：`check-contract` 增加"正则引用的标签都存在"一项并通过。
**依赖**：W1、W3。

### W5 · 内容：22 塔罗人设（第一批）

**做什么**：22 位可操作角色的七段人设 + 十级台阶 + 行间支援。

**怎么做**
1. 先出**骨架表**：每人 6 个标题 + 10 行戏眼（1 天）
2. 逐人扩写：每级 2–4 句，2,000 字/人（6 天）

4. 生成条目：`tools/gen-people.mjs` 读 `src/data/chars.json` → 输出世界书条目

**产物**：`src/data/chars.json`、`dist/card.json` 中 +22 条
**验收**：`check-names` 零变体；每人的门槛维与 `08` 表一致。
**依赖**：需要你给「最想先攻略的 3 个人」。
