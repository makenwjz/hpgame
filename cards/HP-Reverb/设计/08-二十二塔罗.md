# 08 · 二十二塔罗：可操作角色（重排 v2）

> 本版按最新 canon 重排：
> - 主角 = **0 愚者 · 男哈利**；**哈莉 = 21 世界**，序章末加入，**没有自己的宫殿**。
> - **阿利安娜 = 13 死神**，序章即入队，平时伪装成主角的**猫**（定位同摩根娜）。
> - **德拉科娅 = 3 皇后**，**麦格 = 4 皇帝**；卢娜 = **18 月亮**。
> - **韦斯莱双子 = 8 力量**（一个操作位、两具身体）。
> - 詹玛、莉莉、妮可、阿尔巴、格林德沃 **不是可操作对象**。
> - 初始队（序章）：**哈利、罗娜、赫敏、阿利安娜**。

## 1. 世界观前提：女女生育

巫师界以**女女魔药生育**为主流，所以：

- **波特家**：詹玛·波特 + 莉莉·波特，两位母亲，均已故。
- **马尔福家**：露西娅·马尔福 + 纳西莎·马尔福，两位母亲；德拉科娅是独女。
- **韦斯莱家**：莫莉娅 + 阿蒂娅，两位母亲，七个孩子。
- 麻瓜世界仍是男女家庭（德思礼家照旧）。

**这条设定不是背景板**：它决定了「家族压力」长什么样。
纯血家族逼的不是「传宗接代」，是**血脉纯度**与**联姻对象**——马尔福两位母亲对德拉科娅的期待，是「别让这个家在白纸上断掉」。

## 3. 序章四人组

| 角色 | 位置 | 说明 |
|---|---|---|
| 哈利（0） | 主控 | 玩家自己；盗贼，速度与偷取 |
| 罗娜（1） | 输出 | 黑魔，第一场战斗的火力 |
| 赫敏（2） | 解谜 | 学者，识破与弱点共享 |
| **阿利安娜（13）** | 向导 | 平时是猫；战斗时现形，白魔 |

**阿利安娜的猫形态**

- 平时：黑猫，蹲在哈利肩上；不占队伍位，不吃伤害。
- 发言：只有哈利能听见她说话（其他人听到猫叫）。
- 进宫殿：在门口现形，占第 4 席。
- 能力：白魔（治愈 / 净化 / 守护 / 满血复活）；被动「每局 1 次满血复活」。
- **秘密**：她为什么是猫、为什么活到 1991 年——第 06 学年她自己的宫殿里才揭开。

> 她的定位是摩根娜：嘴碎、爱管、关键时刻最靠得住。但她不是「吉祥物」，她是全卡最重要的向导。

## 4. 韦斯莱双子（8 力量）

**一个操作位，两具身体。**

| 项 | 规则 |
|---|---|
| 占位 | 只占 1 个队伍位，但战场上有两个可被攻击的目标 |
| 行动 | 每回合行动 **1 次**，由一名双子执行；另一名可「接力」（同一技能由第二人续一段） |
| HP/MP | 共享一条 HP 条（两条命合并），一人倒下则另一人属性 −30% |
| BP | 共享 |
| 专属技能 | 「一人引、一人打」：本回合造成的伤害下回合延迟生效，但伤害 ×1.6 |
| 加入 | 社群 Rank 5（两人的 Rank 分别算，取较低那个） |

**平衡**：他们不是「两个人各打一次」，而是「一个人的位置打出两个人的花样」。强在连携，弱在一人倒下就废一半。

## 5. 不可操作但仍在故事里的人

| 角色 | 处理 |

| 詹玛·波特 | 已故。只在追忆线、照片、墓前出现；提供一次剧情增益 |
| 莉莉·波特 | 已故。同上；是哈莉与斯内普两条线的共同锁 |
| 妮可·勒梅 | 不在队。行间/信件里的炼金顾问，可合成装备 |
| 阿尔巴·邓布利多 | 不在队。校长，任务发布者；她的「棋局」不设宫殿 |
| 格林德沃 | 不在队。终局对手之一，关在纽蒙迦德；不设宫殿 |
| **露西娅·马尔福** | 不在队，但**可攻略**（T2，7 级）。掌权的纯血家主；与德拉科娅、纳西莎三条线**互不冲突**，见 `12` §5.1 |
| **纳西莎·马尔福** | 不在队，但**可攻略**（T2，7 级）。护短的那位母亲；门槛是共情，见 `12` §5.1 |

**她们仍然存在、仍然重要**，只是玩家不能操作。这一条把 22 个位置留给「能陪你走进去的人」。
注意：**不可操作 ≠ 不可攻略**——露西娅就是反例。

## 7. 加入条件一览

| 类型 | 条件 |
|---|---|
| 序章 | 哈利、罗娜、赫敏、阿利安娜 |
| 序章末 | 哈莉（世界） |
| 社群 Rank | 秋 3 / 娜薇 3 / 菲伦萨 3 / 波莫娜 4 / 奥莉芙 4 / 塞德丽卡 4 / 卢娜 4 / 金妮 4 / 双子 5 |

| 不可加入 | 伏地魔 |

**哈莉为什么没有宫殿**：她不属于这个世界，她的心没有在这边长出建筑。
她的终局不是「改心」，是**选择**——留下、回去、还是你跟她走（见 `07-序章与哈莉线.md`）。
