## 2. 共同规则

- 宫殿主的社群 Rank 上限锁 5，改心后解到 10；Rank 9 的「恋」分支必须改心后。
- 每座宫殿一个截止周；逾期 → 宫殿暴走：宫殿主失联或敌对，网边断两条，下学年一条交叉线永久关闭。
- 每学年地图重组，允许反复进，但秘宝只在「她准备好」时出现（通常 Rank ≥3）。
- 改心后宫殿坍塌，改为「回忆房间」，只能看不能走。
- Boss 三阶段（100–60 / 60–30 / 30–0），护盾 3→4→5，切阶段暂停交给模型写戏。

## 3. 第 01 学年：两座

一年两座，是整卡唯一一次「一年级就这么重」。理由很直接：**斯内普与德拉科娅是主角最早撞上的两堵墙**——一个用冷，一个用身份。

### 1 · 混血王子的地窖（斯内普｜隐者 IX）

**欲望**：把 1981 年那个下午留在原地。
**真正的欲望**：有人替她说一句「不是你的错」。

| 层 | 主题 | 画面 |
|---|---|---|
| 1F | 无限魔药储藏室 | 所有标签写着同一个日期 |
| 2F | 记忆循环走廊 | 同一句话重复，每次少一个字 |
| 3F | 学生时代的教室 | 她坐在最后一排 |
| 4F 核心 | 停在下午三点的房间 | 窗外阳光不动 |

- **机关（配药）**：按顺序取三味材料；错序生毒雾（HP −10、警戒 +5）。配方碎在房间里，集齐才看得懂。
- **守门**：记忆里的她自己（不能攻击，只能听她说完；打断一次本层重来）。
- **秘宝**：三十年前的一封信，收信人姓波特。
- **真相碎片**：① 她求伏地魔放过莉莉 ② 她去找邓布利多 ③ 她抱着她。
- **改心后**：她第一次说出没有修饰的那句话。Rank 6 起，批评里开始带「别学我」。
- **掉落**：配比残页（材料：魔药类战斗 +8）。
- **基调**：冷、窄，永远有药味。

### 2 · 马尔福庄园的地基（德拉科娅｜皇后 III）

**欲望**：被家族承认为「完美的继承人」。
**真正的欲望**：被两位母亲中的任何一位，当成孩子而不是筹码。

| 层 | 主题 | 画面 |
|---|---|---|
| 1F 门面 | 修剪成家徽形状的温室 | 太亮、太整齐 |
| 2F | 镜廊 | 每面镜子里是「更好的她」 |
| 3F | 家族画像长廊 | 所有祖先同时转头 |
| 4F | 账房 | 账本上写着她从小到大的「价值」 |
| 5F 核心 | 母亲的房间 | 两位母亲的梳妆台，只有一张被用过 |

- **机关**：按家徽顺序拉杆（龙—蛇—杖—冠）。错序 → 灌水，本层重来。
- **镜像**：镜厅出现「假同行」，行为一样但不说话；攻击它掉警戒。
- **守门**：家徽巨人（弱点：缴械 / 石化）。
- **秘宝**：银蛇袖扣——一位母亲给的，她一次没戴过。
- **真相碎片**：① 一位母亲说「你还不够」 ② 她烧掉自己写的信 ③ 她在镜子前练习笑。
- **改心后**：她能说「我不想成为这个家」。Rank 6 起第一句从「报姓」变成「你来了」。
- **掉落**：银蛇袖扣（饰品：对纯血家族判定 +5）。
- **基调**：太亮、太整齐，玻璃反光里总有人慢半拍。

> **两位母亲**不是摆设：掌权的露西娅、护短的纳西莎，在宫殿里各留一件东西。改心不是反抗家族，是第一次分清「哪一位的话她真的在乎」。
>
> **露西娅与纳西莎都可攻略（T2，7 级），且与德拉科娅不冲突。** 三人可以同时推进，互不关闭「恋」。
> 这座宫殿的 5F 留着露西娅写给「将来会站在这个房间里的人」的信；3F 画像长廊尽头是纳西莎偷偷挂上去的一张女儿小时候的画。
> 唯一硬规则：**不能骗**——家族知情度（按三人 Rank 推导）≥60 后，同时答应两人会掉三人的点。详见 `12` §5.1。

## 4. 其余七座

### 3 · 五十年前的日记（托玛｜恶魔 XV｜02 学年）

**欲望**：被爱，或被所有人记住。
**真正的欲望**：有人在她还是孩子时，选她一次。

| 层 | 主题 |
|---|---|
| 1F | 整洁的孤儿院，所有孩子在笑同一段 |
| 2F | 每个房间有一个「更讨人喜欢的你」 |
| 3F | 奖品陈列室，每件奖品刻着别人的名字 |
| 4F | 地下室，她第一次学会「交换」 |
| 5F 核心 | 只有一面镜子的房间，镜子里没有她 |

- **机关（契约）**：接受她的好意要抵押一段记忆（五维经验 −1 或掉一件战利品）；可以拒绝，拒绝会关一扇门。
- **守门**：十六岁的她（不能攻击，只能回答三个问题）。
- **秘宝**：日记本的一页。
- **碎片**：① 她第一次被选中又被退回 ② 她学会笑的那天 ③ 她写下自己的名字。
- **改心后**：她第一次问「如果我不是那样呢」；`心志` 持续扣减停止。
- **掉落**：日记页（消耗品：说服 +5，每次扣 1 心志经验）。

### 4 · 第十二年的牢房（天狼星｜塔 XVI｜03 学年）

**欲望**：让虫尾巴付出代价。
**真正的欲望**：有人相信他一次。

| 层 | 主题 |
|---|---|
| 1F | 走不到头的牢房走廊 |
| 2F | 每扇门后都是他家的客厅，家具一次比一次旧 |
| 3F | 摄魂怪巡房，灯火灭即被追 |
| 4F | 通缉令墙，每张脸都是他 |
| 5F 核心 | 有摩托车和一张合影的车库 |

- **机关（巡逻）**：摄魂怪固定路线，视野 4 格；灯火 <50 主动追。被追上掉 20 灯火 + 警戒 15。
- **守门**：他的通缉令（会说话；撕掉它 = 承认自己是逃犯）。
- **秘宝**：四个人的合影。
- **碎片**：① 他被冤枉那晚 ② 他追出去 ③ 他笑了。
- **改心后**：他愿意先活下去再谈复仇。
- **掉落**：合影（饰品：同伴支援 +1）。

### 5 · 满月的房间（卢平｜倒吊人 XII｜03 学年）

**欲望**：让自己从所有人的记忆里消失。
**真正的欲望**：有人在他变成狼的那一夜，仍然留在门外。

| 层 | 主题 | 画面 |
|---|---|---|
| 1F | 永远锁着的宿舍 | 月相挂在窗外，不变 |
| 2F | 「他离开之后」的房间 | 每个人的生活都更好 |
| 3F | 尖叫棚屋的通道 | 墙上有他自己抓的痕 |
| 4F 核心 | 四个人的宿舍，只有三张床 | 第四张被拆了 |

- **机关（月相）**：每层月相推进一档；满月时狼形出现，**不能打，只能躲**（追逐战，视野 5 格）。
- **守门**：狼形的自己（不攻击，只挡路；接受它才能过）。
- **秘宝**：一张没有他的合影。
- **碎片**：① 他咬人那晚 ② 他推开所有人 ③ 他其实想留下。
- **改心后**：他第一次答应「留下吃饭」，而不是先走。
- **掉落**：月相护符（饰品：夜晚视野 +1，白天 −1）。

### 6 · 重复的走廊（海伦娜｜命运之轮 X｜04 学年）

**欲望**：重来一次，把冠冕还回去。
**真正的欲望**：有人来找她，而不是来找冠冕。

| 层 | 主题 |
|---|---|
| 1F | 螺旋楼梯，每层一样，刻痕在变多 |
| 2F | 同一个选择重复出现，结果一次比一次接近她想要的 |
| 3F | 画像走廊，画像在复读她的话 |
| 4F 核心 | 有冠冕的房间，冠冕浮着，下面没有台子 |

- **机关（回溯）**：每层可回溯一次（灯火 −10）；房间会记住上次选择，同一机关第二次答案不同。
- **守门**：另一个自己（每个选择都相反；赢她 = 承认另一种活法）。
- **秘宝**：回响。
- **碎片**：① 她偷走冠冕 ② 她逃走 ③ 她一直在等有人来。
- **改心后**：她放下冠冕。
- **掉落**：回响（饰品：每层回溯一次）。

### 7 · 规章的迷宫（麦格｜皇帝 IV｜05 学年）

**欲望**：只要所有人守规矩，就不会有人死。
**真正的欲望**：有人告诉她「那不是你的错」。

| 层 | 主题 | 画面 |
|---|---|---|
| 1F | 无限走廊，墙上全是校规 | 每条都标着年份 |
| 2F | 每条校规对应一个「如果当初」 | 走廊尽头是一间空教室 |
| 3F | 点名册房 | 念到名字的人消失 |
| 4F | 她自己的办公室 | 桌上摊着没批完的作业 |
| 5F 核心 | 一间没有规则的房间 | 她坐在里面，第一次没有站着 |

- **机关（违规）**：必须违反一条校规才能前进。每违反一条：声望 −1 或警戒 +10（二选一）。
- **守门**：她的点名册（念出一个名字，那个人这一层不能再动；打断它要靠其他队员）。
- **秘宝**：一支用旧的教鞭。
- **碎片**：① 她第一次扣分 ② 她没能救下的学生 ③ 她其实知道规矩救不了人。
- **改心后**：她第一次说「这次不算你违规」。
- **掉落**：教鞭（武器：对「规则类」敌人 +5）。

### 8 · 没有发生的那一天（阿利安娜｜死神 XIII｜06 学年）

**欲望**：那个下午没有发生。
**真正的欲望**：有人承认她真的死了——哪怕她现在是一只猫。

| 层 | 主题 | 画面 |
|---|---|---|
| 1F | 阳光很好的客厅 | 茶一直热着，窗外永远同一个下午 |
| 2F | 同一段下午循环 | 家具每次错位，台词少一句 |
| 3F | 楼梯 | 每一步都听见楼上的争吵 |
| 4F 核心 | 一扇打不开的门 | 门后没有声音，也没有风 |

- **前置**：她是你的猫、你的向导；进这座宫殿时**猫形在门口失效**，她第一次以人形站在你面前。
- **机关（循环）**：找出「正确的那一次下午」，线索是家具位置与缺失的字；选错重置整层（灯火保留）。
- **守门**：没有守门人。整间没有对白的房间，只有你和她，和十分钟沉默。走出房间即通过。
- **秘宝**：一只没织完的袜子。
- **碎片**：① 三个人的争吵 ② 她下楼 ③ 之后没有人再提她。
- **改心后**：她允许自己被记住为「死了」；Rank 6 起终于肯说自己的名字，也肯变回猫。
- **掉落**：没织完的袜子（饰品：一次免死，代价警戒 +10）。

### 9 · 魂器墓园（伏地魔｜审判 XX｜07 学年）

**欲望**：不死。

| 层 | 主题 |
|---|---|
| 1F | 安静的墓园，每块墓碑都没有名字 |
| 2F | 每座墓都是一次死亡的重演 |
| 3F | 分裂的祭坛，七道裂口 |
| 4F | 她小时候的孤儿院走廊 |
| 5F 核心 | 一口空棺材，里面铺着小时候的毯子 |

- **机关（七魂器）**：七个碎片散在各处，每破坏一个整张地图重写一次。
- **守门**：她自己（不可战胜，只能「看见」；打法是把七个碎片全部看完再走出墓园）。
- **秘宝**：一片灵魂碎片。
- **碎片**：① 她怕死的那天 ② 她第一次分裂 ③ 她已经不记得自己的脸。
- **改心**：**不可改心**，只能审判。走出墓园触发终局分支。
- **掉落**：无。

## 6. 改心三拍（模板）

1. **看见**：拿到秘宝，也看见她不愿承认的那件事。
2. **不救**：你不能替她解决，只能把看见的东西放在她面前。
3. **她变**：变化要小。不是「从此善良」，是「第一次没有说那句话」。

> 德拉科娅改心后，照旧抬头报姓——说到一半停了，改口说「你来了」。就这一处不同。
