# 06 · 宫殿：像素潜入小游戏

> 本文件取代 `03-行间对峙回声.md` 里的「行间 / 部位 / 门」结构。
> **保留**：对峙公式、十类检定、三档结算、失败不判死。
> **改名**：行间 → **宫殿**；部位 → **房间**；回声 → **警戒**；意志 → **意志**（不变）；残留 → **碎片 / 秘宝**。
> 新增：像素探索层、22 张塔罗、宫殿主、改心。

---

## 0. 一句话

**现实是日程表，宫殿是像素地图。** 白天在霍格沃茨做选择，夜里钻进某个人心里的那栋房子，找到他/她藏得最深的那件东西。

每座宫殿有主人。**宫殿主不是怪物，是你认识的人**——她可能刚和你吃过饭。

---

## 1. 为什么从「肉鸽」改成「宫殿」

| 维度 | 行间（旧） | 宫殿（新） |
|---|---|---|
| 空间 | 随机节点，文字描述 | **固定像素地图，玩家自己走** |
| 随机性 | 每次不同 | 每层骨架固定，走廊与侧室按种子变化 |
| 目标 | 走到第 5 重 | **拿到秘宝，改心** |
| 敌人 | 抽象「对峙」 | 地图上有视野、巡逻、追击的**认知存在** |
| 失败 | 回声满被打出 | 警戒满 / 体力归零 / 被包围，**强制撤退** |
| 情绪 | 紧张 | **潜入的偷感**——你在别人家里 |

**关键判断**：模型不擅长空间。让大模型描述「你往左走三步」既慢又容易自相矛盾。
所以把**走地图**这件事交给前端（canvas 像素游戏），把**写故事**留给模型。

> UI 玩，模型写。这句话是这份设计的全部技术前提。

---

## 2. 三层结构

```
现实层（霍格沃茨）
  · 日程 / 行动点 / 社群 / 考试 / 期限
  · 你在这里认识宫殿主
        ↓ 晚上潜入（2 行动点）
宫殿层（像素探索）
  · 地图 / 迷雾 / 认知存在 / 钥匙 / 安全屋 / 商店
  · 拿到秘宝 = 通关
        ↓
现实层（改心）
  · 她变了，还是没变
  · 网边重算，社群重算，期限结算
```

**一条铁律**：宫殿里发生的事，必须回到现实产生后果。改心不是通关动画。

## 5. 像素关卡规格

| 项 | 规格 |
|---|---|
| 视角 | 俯视 2D |
| Tile | 16×16 px，屏幕 2× 放大 |
| 地图 | **24 × 18 tile**（384×288 px 逻辑分辨率） |
| 视口 | 15 × 9 tile，相机跟随 |
| 调色 | 每座宫殿一套 4 色主色 + 4 色中性（见 §6） |
| 精灵 | 全程序绘制（矩形/像素数组），**不使用任何外部美术素材** |
| 帧率 | 逻辑 30 fps，移动一格 120 ms |
| 存档 | `/宫殿` 容器 + localStorage 兜底 |
| 种子 | mulberry32，种子存变量，同一层可复现 |

**为什么是 24×18**：一屏 15×9 能看到大半层，纯键盘走完一层约 40–60 步、3–5 分钟。太长会打断聊天节奏。

## 7. 一层的玩法循环

```
进入层
  ↓
黑雾覆盖全图（未探索）
  ↓
移动（每步 1 回合）
  ├─ 视野 3 格（隐者 4 格）
  ├─ 认知存在按各自 AI 行动（巡逻 / 追击 / 固定 / 潜伏）
  ├─ 被看见 → 警戒 +
  ├─ 踩到房间 → 触发房间事件
  └─ 找到楼梯 → 下一层
  ↓
层结算：警戒、体力、碎片、道具
```

### 7.1 房间类型

| 房间 | 占比 | 内容 |
|---|---:|---|
| 空房 | 30% | 一句环境描写，一个可拾取物 |
| 走廊 | 25% | 纯通行，可能有巡逻 |
| 宝箱 | 12% | 碎片 / 道具 / 加隆 / 钥匙 |
| 战斗房 | 12% | 固定认知存在，打赢给钥匙或碎片 |
| 锁门 | 10% | 需要钥匙；钥匙在别处 |
| 安全屋 | 8% | 存档 + 恢复 + 换队伍 |
| 商店 | 5% | 用加隆买消耗品（皇帝 −20%，恶魔卖禁忌） |
| 陷阱 | 5% | 警戒 +10 或体力 −10 |
| 楼梯 | 每层 1 个 | 下一层 |
| 秘宝房 | 顶层 1 个 | Boss 前厅 |

### 7.2 认知存在（敌人）

| 类型 | 视野 | 移动 | 行为 |
|---|---:|---|---|
| 游荡者 | 3 | 1 格/回合 | 随机巡逻 |
| 猎手 | 4 | 2 格/回合 | 发现后直线追击，3 回合放弃 |
| 哨兵 | 5 | 0 | 固定，正面视野扇形 |
| 潜伏者 | 1 | 0 | 只在你踩到相邻格时触发 |
| 宫殿主的影子 | 6 | 2 格 | 顶层专属，不会放弃追击 |

**接触 = 进入对峙**（不是实时战斗）：UI 冻结并注入一条遭遇消息，交给模型 + 掷骰脚本处理。
**避免**：UI 不掷骰、不算胜负——抗作弊链路保持唯一入口。

### 7.3 警戒（原「回声」）

| 事件 | 警戒 |
|---|---:|
| 被看见一次 | +5 |
| 被追击每回合 | +2 |
| 触发陷阱 | +10 |
| 对峙失败 | +15 |
| 使用强力道具 | +5~10 |
| 安全屋休息 | −15 |
| 换层 | −5（下楼喘口气） |

| 区间 | 状态 |
|---|---|
| 0–39 | 安静 |
| 40–59 | 有人在找 |
| 60–79 | 封锁：门被锁，商店关闭，敌人 +1 视野 |
| 80–99 | 围捕：每层刷新 1 个猎手 |
| 100 | **强制撤退**（见 §9） |

## 8. 秘宝与改心

### 8.1 拿秘宝

顶层有秘宝房，门口是**宫殿主的影子**。

- 三种过法：打赢影子 / 绕过它（需要钥匙 ×2）/ 用一次「说教」（教皇牌）
- 拿到秘宝 → 宫殿开始崩塌 → 必须在 10 回合内回到入口
- 崩塌期间敌人全部变为猎手，警戒只增不减

### 8.2 改心的后果（不是动画）

| 改心时的社群 Rank | 结果 |
|---|---|
| ≥7 | 她清醒后第一件事是找你。Rank **+1**，隐秘边全部显形 |
| 4–6 | Rank 不变，但她多一句只对你说的话 |
| ≤3 | 她意识到有人看过她的心。Rank **−1**，且三个月内不接受同行 |

**改心不可逆**。宫殿崩塌后不会重建。
**改心也不等于攻略**：你可以改一个人的心，同时永远不和她成为朋友——甚至她会怕你。

### 8.3 改心与主线

大宫殿通关 = 主线节点推进。
小宫殿通关 = 该角色「同行资格」提前解锁（不用等 Rank 5），但 Rank 仍按点数走。

## 9. 失败

| 情况 | 结果 |
|---|---|
| 警戒 100 | 强制撤退：碎片减半，**断一条网边 / 同行者受伤 / 期限提前一周** 三选一 |
| 体力归零 | 被扔回现实：碎片全失，伤势 +30，社群点 −5（她听说你出事了） |
| 崩塌倒计时归零 | 秘宝留在里面，宫殿关闭 **30 天**（一个期限周期），期间不可再进 |
| 主动撤退 | 带走全部碎片（受层数限制），无惩罚 |

**失败不判死**（沿用）。最重的是「断一条边」——那比死更疼。

## 10. 与现实的接口

| 动作 | 现实成本 |
|---|---|
| 潜入一次 | **2 行动点**，占周末 |
| 潜入后次日 | 体力 −10，行动点 −1 |
| 宫殿通关 | 主线/社群推进，改心结算 |
| 被强制撤退 | 世界伤 +1，期限倒计时 −1 周 |

**期限绑定**：每座大宫殿有一个「她会在期限前做完某件事」的硬截止（写进学年线）。
逾期未通关 = 她的扭曲定型，该宫殿永久关闭，相关网边全部转「破裂」。

## 11. 技术架构

```
┌─────────────────────────────────────────────┐
│ 酒馆楼层 iframe（无沙盒）                    │
│  ├─ <canvas> 像素层（16×16 tile, 2×）        │
│  ├─ HUD（体力/魔力/警戒/意志/碎片/钥匙）      │
│  └─ 触屏 D-pad + 键盘                        │
└───────────────┬─────────────────────────────┘
                │ Tavern Helper API
                ▼
┌─────────────────────────────────────────────┐
│ MVU 变量 /宫殿                              │
│  {种子, 层, 坐标, 警戒, 体力, 意志, 钥匙,    │
│   碎片[], 队伍[], 领队, 已探索[], 敌人[]}     │
└───────────────┬─────────────────────────────┘
                │ 楼层事件 / 摘要注入
                ▼
┌─────────────────────────────────────────────┐
│ 模型：写叙事；对峙脚本：掷骰                  │
└─────────────────────────────────────────────┘
```

### 11.1 输入

- 键盘：`WASD / 方向键` 移动，`空格` 交互，`Tab` 换领队，`Esc` 菜单
- 触屏：左下方向键，右下 A（交互）/ B（菜单）
- 每次移动 120 ms 节流，防止连点

### 11.2 状态同步

- **每步不写变量**（太频繁）。每 10 步或进房间时写一次 `/宫殿`。
- 离开层 / 撤离 / 失败 → 写完整快照 + 注入一条摘要消息：

```
[宫殿] 第2层 · 取得「西侧钥匙」 · 击退 2 只认知存在 · 警戒 41 → 58
```

模型读到这条摘要，写 2–4 段叙事，不需要知道地图长什么样。

### 11.3 确定性

- 地图由 `种子 + 层号` 生成，同一层每次进入一致（除非宫殿崩塌重建）。
- 敌人初始位置、宝箱内容同理。
- RNG 只在「战斗掷骰」处，由脚本提供。

### 11.4 降级

- 无 JS / iframe 失败 → 显示纯文字地图（每层一张 ASCII 图）+ 方向指令。
- 变量未就绪 → 显示「宫殿还在重组」，不写入。

## 12. 生成算法（骨架 + 种子）

每座宫殿手工写**骨架**，程序只填**血肉**：

```
骨架（手工，写在宫殿条目里）：
  第1层：主题「门厅」；必有 入口、锁门、安全屋；秘宝方向 = 西北
  第2层：主题「走廊」；必有 2 个战斗房、1 个商店
  ...
  顶层：秘宝房 + 宫殿主的影子

血肉（程序，种子决定）：
  1. 24×18 网格划成 6×4 个 4×4 房间格
  2. 选 6–9 个房间格作为房间，按骨架强制指定若干
  3. 最小生成树连接 + 额外 1–2 条环（防止死路）
  4. 按骨架配比填充房间类型
  5. 放置钥匙（锁门数 = 钥匙数）
  6. 放置敌人（按层的难度预算）
  7. 撒一层装饰瓦片（地毯、碎纸、血迹、积灰）
```

**为什么不全随机**：全随机的地图没有叙事。宫殿是「她的心」，门厅、走廊、秘宝房必须有意义。
**为什么不全手工**：22 座 × 3–5 层 = 70–100 张图，手工做不完，而且每次进去都一样会腻。

## 13. 垂直切片：第一座宫殿

先做 **皇帝 · 德拉科娅 ·「马尔福庄园的地基」**，3 层（正式版 5 层）：

| 层 | 主题 | 关键房 | 敌人 |
|---|---|---|---|
| 1 | 门厅 · 家徽 | 入口、锁门、安全屋 | 游荡者 ×2 |
| 2 | 长廊 · 画像 | 战斗房 ×2、商店 | 猎手 ×1、哨兵 ×1 |
| 3 | 地基 · 纹章室 | 秘宝房、宫殿主的影子 | 影子 ×1 |

**验收**：
1. 能走完 3 层，拿到秘宝
2. 至少被看见一次、警戒 ≥40
3. 至少触发一次对峙并回到游戏
4. 通关后改心结算写回社群
5. 断网时显示 ASCII 降级图

## 14. 取舍与风险

| 风险 | 处理 |
|---|---|
| 手机操作难 | 触屏 D-pad + 单击移动（点哪走哪） |
| 前端太占 token | 像素层是代码不是文本，**不占提示词**；只注入摘要 |
| 模型不知道地图 → 叙事对不上 | 摘要里写「层/房间/事件」，不写坐标 |
| 22 座做不完 | 8 大 + 14 小，小的 2–3 层，先做 1 座验证 |
| 玩家只想聊天不想玩 | 提供「自动探索」：不出图，只按概率结算（老式文字潜入），随时可切 |
| 改心太强/太弱 | 改心只改 Rank ±1 与网边，不给数值飞跃 |

**最后一条很重要**：像素小游戏是**可选的深度**，不是门槛。不想玩的人用文字模式，一样能通关。

## 15. 与世界观的缝合

宫殿不是外挂系统，它有明确的魔法解释：

- 霍格沃茨的墙会记事（`正文格式` 里已有这一句）；
- 摄神取念可以看见记忆，但用咒语硬闯会把人逼疯；
- 宫殿是**「用记忆搭出来的空间」**，比摄神取念温和，但代价是你会看见她不想给你看的那部分。

所以宫殿有三条规矩，写进常驻：

1. **不能对同一个人反复潜入**——宫殿崩塌后重建需要时间（30 天）。
2. **看见的东西不能拿来当把柄**——用宫殿里看到的事威胁她，网边立刻转「破裂」。
3. **宫殿主知道有人来过**——改心后她记得那种「被打开」的感觉，哪怕不记得细节。

这三条让宫殿从「刷子游戏」变成「有后果的行为」。
