# 01 · 时间、日程、五维、考试

> 本文件展开三个咬合的模块：**时间轴**（周 / 时段）、**行动点**（玩家的稀缺资源）、**五维**（门槛）。
> 三者共用一套刻度，见 `00-总纲与契约.md` §2。

---

## 1. 时间轴

### 1.1 为什么以「周」为单位

v10.1 用「日 + 八档时段」，结果是模型每天都在算日期，玩家感觉不到「这一年快用完了」。
Persona 的压力来自**日历翻页**，不是钟点。所以把最小刻度从「半天」抬到「周」：

- 一周 = 4 个行动点，玩家做 4 个决定；
- 一周结束 = 日历进 7 天；
- 一学年 = 43 周 = 172 个决定 = 172 个点。

这样「还剩 12 周」这句话才有重量。

### 1.2 日期映射（精确对齐，不走估算）

`日期 = 1991-09-01 + (周 − 1) × 7 天`

| 周 | 起 | 止 | 事件 |
|---:|---|---|---|
| 1 | 09-01 | 09-07 | 开学、分院、第一夜 |
| 9 | 10-27 | 11-02 | **万圣夜（10-31）· 第一次涨潮** |
| 17 | 12-23 | 12-29 | **圣诞（12-25）· 第二次涨潮** |
| 18 | 12-30 | 01-05 | 圣诞节假期（第 18 周不消耗行动点，只有剧情） |
| 21 | 01-20 | 01-26 | 期中考试 |
| 42 | 06-15 | 06-21 | 期末考试周（不可潜入） |
| 43 | 06-22 | 06-28 | **期末（06-26）· 第三次涨潮 + 学院杯结算** |

日期由**日程脚本**写，不由模型算。模型只负责叙事，禁止在正文里写「三天后」这种相对时间当日期。

### 1.3 时段只剩四档

| 时段 | 何时 | 能做什么 |
|---|---|---|
| 上午 | 上课日、周末白天 | 上课 / 自习 / 采买 / 打工 |
| 下午 | 周三 | 自由行动 |
| 黄昏 | 周五 | 自由行动 |
| 夜晚 | 周六 / 周日；或任意潜入夜 | 夜谈 / 潜入 |

**slot → 时段映射**（写死在脚本里）：

| slot | 常规 | 若为潜入 |
|---|---|---|
| 周三 | 下午 | 夜晚 |
| 周五 | 黄昏 | 夜晚 |
| 周六 | 上午 | 夜晚 |
| 周日 | 上午 | 夜晚 |

## 2. 行动点

### 2.1 基本规则

- 每周 **4 点**，对应周三 / 周五 / 周六 / 周日各 1。
- **不累积**：周日结束无论剩几点，清零。
- 潜入占 **周六 + 周日**（2 点），当日之外不能补。
- 点用完 → 自动进入下周一（周结算）。
- 玩家可以主动「休息」提前结束一周——**这本身是个选择**（早结束 = 少做一件事，但恢复更多）。

### 2.2 七个行动

| 行动 | 点 | 允许 slot | 产出 | 叙事要求 |
|---|---:|---|---|---|
| **陪人** | 1 | 周三/周五/周六/周日 | 按 `<affinity>` 的 kind 结算社群点（+2~10，常见 +8）；可能触发 Rank 戏 | 必须是一整场两人独处的戏，不能一句话带过 |
| **自习** | 1 | 任意 | 指定一维 **+1 经验**（受子上限约束） | 写清在哪儿学、遇到谁、学到什么 |
| **打工** | 1 | 周三/周五/周六 | 加隆 **+40~80**；胆识或共情 +1 经验 | 写明雇主与活计 |
| **采买** | 1 | 周三/周五/周六 | 买 1–3 件（价格见 `04`） | 写明在哪个铺子 |
| **短行动** | **0**（每周 1 次） | 任意 | 社群点 +2，或一件 5 加隆以内的小物 | 只能是一句话级别：递话、看一眼、塞东西 |
| **休息** | 1 | 任意 | 体力 +25、魔力 +25、伤势 −10 | 可写成睡一天、泡校医院、一个人待着 |
| **潜入** | 2 | 周六 + 周日 | 一个 run（见 `03`） | 周六入夜进，周日天亮出 |

### 2.3 行动点的叙事换算

1 点 ≈ 1–2 天。模型不需要逐日铺陈，但每次行动必须给出：

1. **在哪**（场景名，用「·」分层）
2. **和谁**（若无，写清独处）
3. **做了什么具体的事**（不是「度过了一天」）

反例（不许）：`周三，你在城堡里闲逛，感觉很充实。`
正例：`周三下午，你在图书馆靠窗第三排坐下，把《标准咒语·二级》摊开，赫敏·格兰杰的笔尖声在旁边响了一整个下午。`

### 2.4 子上限（防刷）

每学年每维度最多获得 **12 经验**，且各来源另有子上限：

| 维度 | 来源 | 每年上限 |
|---|---|---:|
| 学业 | 上课（每 2 周 1） | 10 |
| 学业 | 自习 / 复习 | 8 |
| 学业 | 考试 O/E | 2 |
| 胆识 | 高风险检定成功 | 4 |
| 胆识 | 顶撞 / 拒绝 / 越界 | 2 |
| 胆识 | 潜入通过一重 | 4 |
| 魅力 | 说服类检定成功 | 3 |
| 魅力 | 送礼得体 | 2 |
| 魅力 | 公开表现（宴会 / 比赛 / 演讲） | 2 |
| 魅力 | 声望折算（学年末，见 §3.4） | 2 |
| 共情 | 安抚式对话 | 3 |
| 共情 | 送礼送对 | 2 |
| 共情 | 照料生灵检定成功 | 2 |
| 共情 | 社群 Rank 戏里「听完了」 | 3 |
| 心志 | 抵抗类检定成功 | 3 |
| 心志 | 守护神成功 | 1 |
| 心志 | 带伤坚持 | 2 |
| 心志 | 主动承担代价 | 2 |

总量 12 是硬帽，子上限只是防止「同一件事刷一年」。

### 2.5 周结算（每周自动，模型不写）

| 顺序 | 动作 |
|---:|---|
| 1 | `/日程/本周已用` 归零，`本周安排` 清空 |
| 2 | `周 +1`，`日期` 按 §1.2 重算，`时段 = 上午` |
| 3 | 体力 +10、魔力 +10；若伤势 ≥50 则只 +5 |
| 4 | 伤势 −5（本周未潜入且未受伤时） |
| 5 | 期限倒计时刷新，写 `/期限/*/状态` |
| 6 | 生日检测：本周有核心角色生日 → 写一条叙事提示 |
| 7 | 每 3 周一次世界事件（霍格莫德周末 / 魁地奇 / 公告 / 涨潮预警） |
| 8 | 连续两周体力 <20 → 强制「休息」并触发一次小病剧情 |

### 2.6 边界情况

| 情况 | 处理 |
|---|---|
| 行动点不够（剩 1 点却要潜入） | 脚本拒绝，回执写「周末被占满了，下周吧」 |
| 同一周重复同一行动 4 次 | 允许，但社群点第 3 次起每次 −2（新鲜感衰减） |
| 一周内陪同一人两次 | 第二次社群点 ×0.5，并提示「她还有别的事」 |
| 潜入后次日 | 体力 −10，当日行动点 −1（本周少一次） |
| 考试周（第 21、42 周） | 禁止潜入；自习产出 ×1.5 |
| 圣诞假（第 18 周） | 行动点归零，只有一段剧情 + 一次礼物结算 |
| 期限周（第 9、17、43 周） | 周末强制结算期限，未完成的直接判逾期 |

## 3. 五维

### 3.1 阶位

| 阶 | 学业 | 胆识 | 魅力 | 共情 | 心志 |
|---:|---|---|---|---|---|
| 1 | 生手 | 怯 | 素 | 钝 | 软 |
| 2 | 跟得上 | 稳 | 清秀 | 客气 | 撑得住 |
| 3 | 拿得出手 | 敢 | 引人 | 会听 | 扛得住 |
| 4 | 尖子 | 狠 | 出众 | 接得住 | 立得住 |
| 5 | 博识 | 无畏 | 摄人 | 通透 | 不动 |

开局全 **2 阶**（十八岁，底子已经有了）。
每阶 **6 经验**，满则升阶、经验归零；升阶时写两三句小演出（不是大戏）。

### 3.2 用法

| 场景 | 用哪一维 |
|---|---|
| 社群 Rank 门槛 | 她最看重的那一维（3 / 4 / 5 阶） |
| 检定修正 | 相关维：`(阶 − 2) × 2`，上限 ±6 |
| 考试 | 学业 |
| 行间部分偶遇 | 胆识 / 共情 / 学业 |
| 三角冲突的选边 | 共情 / 魅力 |

### 3.3 升降

- **只能升**，除了心志。
- 升阶演出由模型写，脚本只改数值。
- 每学年每维 ≤ +2 阶（12 经验）。
- **心志唯一会降**：托玛·马沃拉·里德尔每升 1 级 Rank，心志 −1 阶（不低于 1）。已经用掉的门槛不回收——「你曾经够格过」。

### 3.4 声望折算

声望用阶：−3 ~ +5。

| 声望阶 | 含义 | 学年末魅力经验 |
|---:|---|---:|
| −3 | 恶名昭彰 | 0 |
| −1 | 有人背后议论 | 0 |
| 0 | 无名 | 0 |
| +1 | 同届知道你 | +1 |
| +2 | 全院知道你 | +1 |
| +3 | 全校知道你 | +2 |
| +4 | 上过《预言家日报》 | +2 |
| +5 | 传奇 | +2 |

声望变动：考试 O +2、E +1、D −1；公开比赛胜 +1；当众出丑 −1；被记过 −1；期限逾期 −1。

## 4. 上课与考试

### 4.1 上课（自动，不耗点）

每周自动一次，模型用一句话交代课堂：

- 产出：学业经验 **每 2 周 +1**（一年约 10 点）
- 有 20% 概率触发课堂社交（同学搭话、教师点名、邻座传纸条）——**由模型判断，不掷骰**
- 课堂是**介绍新咒语**的主要渠道：每学年 4 个，进入 `/能力/咒语掌握` 时初始值 0

**课程表（只做叙事，不做熟练度）**

| 年级 | 必修 |
|---|---|
| 1 | 魔咒、变形、魔药、黑魔法防御、魔法史、天文、草药、飞行 |
| 2+ | 加选修：占卜、算术占卜、古代如尼文、保护神奇生物、麻瓜研究、炼金 |

> 注意：**课程不再有独立熟练度**。v10.1 的 14 门课数字全部删除，只保留「咒语掌握」20 条。

### 4.2 考试

每学年两次：期中（第 21 周）、期末（第 42 周）。

```
成绩分 = 学业阶 × 4
       + min(本学年自习次数, 6)
       + 复习行动次数 × 3      # 复习是自习的变体，明确说「复习」，每次 +3 分，每年 ≤2 次
       + 期中加成（期末才用：期中 O +3 / E +2 / A +1）
```

范围约 8–35。

| 分 | 档 | 声望 | 后果 |
|---:|---|---:|---|
| ≥30 | O 优秀 | +2 | 教授类社群门槛 −1 阶（下一学期） |
| 24–29 | E 良好 | +1 | — |
| 16–23 | A 及格 | 0 | — |
| 10–15 | P 差 | 0 | 家长信一封（纯血家族社群 −1 阶门槛压力） |
| <10 | D 不及格 | −1 | **补考期限**：两周内复习一次，否则学年重读（退学风险） |

### 4.3 复习

`<act do="自习" target="学业" note="复习"/>` → 成绩分 +3，但**不加学业经验**（复习不是学习）。
每年 ≤2 次。

### 4.4 与社群的关系

考试不直接加社群点，但它改**门槛**：

- O：所有教授（斯内普 / 麦格 / 弗立维 / 斯普劳特 / 特里劳尼 / 海格）的 Rank 3 门槛 −1 阶
- D：同上 +1 阶，直到补考通过

这一条让「读书」在社交里有回报，但不至于让学业变成万灵药。

### 4.5 咒语掌握（唯一保留的熟练度）

v10.1 的 14 门课熟练度全部删除，只保留这一项——因为检定需要它。

| 项 | 规则 |
|---|---|
| 存储 | `/能力/咒语掌握/{咒语名}`，值 0–20，上限 20 条 |
| 新学 | 课堂每学年引入 4 个；每学一个新咒语，初始 0 |
| 增长 | 上课用到 +1；自习练咒语 +2；战斗成功使用 +1（每周 ≤2） |
| 检定修正 | `floor(熟练 ÷ 2)`，即 0–20 → 0~+10 |
| 不指名 | 请求里没有 `spell` → 该项不计（不按整本记录猜） |

20 条的上限是刻意的：玩家必须选「主修哪几手」，而不是什么都练一点。

## 5. 一学年的节奏（玩家体感）

| 阶段 | 周 | 玩家在干什么 |
|---|---|---|
| 开学 | 1–2 | 建关系、摸清日程、选第一批人 |
| 第一次涨潮前 | 3–8 | 攒行动点、第一次潜入、决定放弃谁 |
| **万圣夜** | 9 | 硬结算：没准备好的人会永久失联 |
| 深秋 | 10–16 | 扩张、三角冲突开始出现 |
| **圣诞** | 17 | 礼物与家族压力 |
| 寒假 | 18 | 纯剧情，一次礼物结算 |
| 期中 | 21 | 考试，决定教授门槛 |
| 冬季 | 22–35 | 第二轮潜入、深线倾向开始成形 |
| 春季 | 36–41 | 收线、Rank 8–10、恋分支 |
| 期末 | 42–43 | 考试 + 学院杯 + 第三次涨潮 |

**一年下来玩家的实际产出**（按 172 点）：

- 陪人 ≈ 70 点 → 约 8 个人到 Rank 4–6，其中 1–2 个到 8+
- 潜入 ≈ 20 点 → 10 次 run
- 自习 ≈ 30 点 → 2 个维度到 4 阶
- 打工/采买 ≈ 20 点
- 休息 ≈ 30 点
- 剩余 ≈ 2 点（被浪费）

这组数就是「一个普通玩家的一年」，也是验收时拿来对照的基准。
