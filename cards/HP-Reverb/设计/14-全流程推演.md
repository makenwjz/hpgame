# 14 · 全流程推演：一周 / 一年 / 七年

> 这份是把整张卡**跑一遍**。不是设定，是流程。
> 每一节都给出：玩家做什么 → 脚本做什么 → 模型写什么 → 状态栏变什么 → 出错怎么兜。
> 冲突以 `设计/README.md` 优先级为准；数值以 `00` §2 为准；宫殿见 `06/07/10`；人见 `08/12/13`。

---

## 0. 闭合的四条判据

一张卡"闭合"不是"内容写完了"，是这四件事都成立：

| # | 判据 | 验证方式 |
|---:|---|---|
| 1 | **任何一层都有出口** | 每个循环（周/宫殿/期限/学年）都能被走完，不会卡死 |
| 2 | **任何数值都有来源与去处** | 加隆、社群点、五维经验、回声、意志，全能追到写它的那一步 |
| 3 | **任何状态都有翻盘路径** | 逾期、被打出、发现度过高，都还有下一步，除了"世界伤" |
| 4 | **任何系统都不写别人的字段** | 单写原则，见 §9 |

**唯一不可逆的只有三样**：改心、逾期、世界伤。其余都能补救——这是整卡的手感底线。

## 1. 一分钟看全流程

```
【开局】站台 → 分院 → 宿舍 → 第 1 周末「同床」（哈莉）
   ↓
【每周循环】4 行动点
   ├ 上课（自动）
   ├ 陪人 / 自习 / 打工 / 采买 / 休息 / 短行动
   └ 潜入 = 宫殿（探索 + 战斗）→ 改心条件
   ↓ 周结算（日期 +7、期限倒计时、生日、世界事件、轮转换席）
【每月/每 3 周】群像事件（8–12 人同场）
   ↓
【每学年 3 次】涨潮：万圣（第 9 周）/ 圣诞（第 17 周）/ 期末（第 43 周）
   ↓ 逾期 → 世界伤 +1（不可逆）
【每学年末】考试 → 学院杯 → 学年结算 → 学年摘要
   ↓
【第 01–07 学年】两座主宫殿 / 年，哈莉的门在每学年行间里
   ↓
【终局四层】期限清算 / 深线 / 社群终局 / 世界结局
```

## 2. 开局：从站台到第一夜

### 2.1 创角（3 栏）

| 栏 | 写什么 |
|---|---|
| 五维倾向 | 3 点，各给某维 +2 经验（满 6 升阶） |
| 魔杖 | 木材 + 杖芯，定起始专精 |
| 学院 | 四选一，定起始关系与网边 |

提交后：写 `/主角/*`、`/五维/*`、初始 `/关系`（罗娜 / 德拉科娅 / 麦格各 Rank 1），`/时空/周=1`。

### 2.2 第一楼（first_mes）

站台 → 穿墙 → 车厢（罗娜）→ 渡湖 → 分院（帽子多问一句）→ 开学宴（邓布利多短话、斯内普看一眼）→ 塔楼单人房第一夜。
**止于睡下。哈莉不在这一楼。**

### 2.3 第 1 周的 4 个行动点

| slot | 建议内容 | 系统 |
|---|---|---|
| 周三 | 认识 1 人（短行动） | 社群 +2 |
| 周五 | 一次自习或探索学校 | 五维 +1 经验 |
| 周六 | 第二次社交 / 采买 | 社群或钱 |
| 周日 | **强制事件：同床** | 秘密系统开 |

**周日夜间**：剧情脚本检测 `周==1 且 哈莉已登场==false` → 插入「第 1 周末·同床」，四个选项：

| 选择 | 发现度 | 哈莉 | 后续 |
|---|---:|---:|---|
| 藏起来听她说完 | +5 | +10 | 开启藏匿玩法 |
| 立刻找麦格 | 0 | −15 | 邓布利多线开，她被带走三天 |
| 送校医院 | +20 | +5 | 画像看见了 |
| 甩开她 | +10 | −30 | 第 3 周行间重逢 |

**四个都不判死**，只改前两周的节奏与初始态度。

## 3. 每周循环（核心）

### 3.1 玩家侧（状态栏看到的）

```
第1学年 · 1991年10月14日 · 下午 · 行动点 1/4 · 距万圣夜 17 天
本周安排：周三 陪人 罗娜 ✔｜周五 自习 ✔｜周六 —｜周日 —
```

### 3.2 一次「陪人」的完整链路

```
① 玩家输入：周三下午，去找罗娜
② 模型判定：这是 `<act do="陪人" target="罗娜·韦斯莱" slot="周三"/>`
③ 日程脚本：本周已用 0→1；时段=下午
④ 模型写戏（2–5 段）：球场的雨、她不肯说的成绩、你递了糖
⑤ 结尾请求：<affinity name="罗娜·韦斯莱" kind="共患难" delta="+10" reason="陪她坐到天黑"/>
⑥ 社群脚本：
   名单校验 ✓ → 幅度夹取 10 ✓ → 周内第一次 ✓
   社群点 68→78 → 新 Rank = 1+7 = 8
   门槛：共情 5 阶？当前 4 阶 ✗ → Rank 停 7
   回执：「她愿意再走近一步，但你还差点什么」
⑦ 状态栏：罗娜 78/100 · Rank 7（差 共情 5 阶）
⑧ 模型最后写 <UpdateVariable>：只写叙事性字段（当前事件），数值由脚本写
```

**注意第 ⑧ 步**：模型**不许**再写 `/关系/罗娜/社群点`。写白名单会拦，回执记 warn。

### 3.3 周结算（周日最后一楼自动）

```
1 本周已用归零、本周安排清空
2 周 +1、日期 +7、时段=上午
3 体力 +10、魔力 +10；伤势 ≥50 只 +5
4 伤势 −5（未潜入时）
5 期限倒计时刷新；进入倒计时周 → 状态栏变红
6 生日检测（本周有人生日 → 写一条提示）
7 每 3 周一次世界事件（霍格莫德周末 / 魁地奇 / 公告 / 涨潮预警）
8 轮转换席（见 §6）
9 连续两周体力 <20 → 强制「休息」
```

### 3.4 一次「潜入」的完整链路

```
① 玩家：周六去宫殿
② 日程脚本：本周已用 +2，体力 −10，/宫殿/在宫殿 = true
③ 选门 → 前端生成第 1 层（种子 = hash(宫殿, 学年, 周)）
④ 探索：移动扣灯火；踩到 `E` → 触发战斗
⑤ 战斗：前端 → 战斗脚本（BP / 护盾 Break / 队列）
⑥ 模型每层写 1–2 段：这一层的空气、这面镜子里是谁
⑦ 拿到秘宝 + 3 碎片 + 退路 → 改心条件齐
⑧ 撤离：写回残留、加隆、深线；体力按 HP% 折回
⑨ 宫殿脚本清 /宫殿/本局，写 /宫殿/{id}/改心 = true
```

**失败也闭合**：

| 情况 | 结果 | 还能做什么 |
|---|---|---|
| 警戒 100 | 强制撤离，碎片减半 | 断一条边 / 某人受伤 / 期限提前一周（三选一） |
| 全灭 | 撤退，碎片全失，体力 −20 | 下次再来，地图重组 |
| 半途退出 | 存档在安全屋 | 下次从安全屋继续 |

## 4. 三次涨潮（学年的三个闸门）

### 4.1 结算流程

```
第 9 / 17 / 43 周周末：
 ① 剧情脚本读 /期限/{事件}
 ② 判定：提前（≥7 天）/ 准时 / 逾期
 ③ 执行后果（写死）
 ④ 写 /世界伤 += 1（仅逾期）
 ⑤ 状态栏播一段收束文本，当天不能再行动
```

### 4.2 三种结果的差别

| 结果 | 奖励 | 代价 |
|---|---|---|
| 提前 | 1 件残留 + 一次关系奖励（网边 +1） | 无 |
| 准时 | 正常推进 | 无 |
| 逾期 | 无 | **执行写死的不可逆后果** |

### 4.3 第 01 学年的三个闸门

| 周 | 涨潮 | 完成条件（任一） | 逾期后果 |
|---:|---|---|---|
| 9 | 万圣夜 | ① 潜入到第 3 层 ② 2 人 Rank ≥3 且拿到情报 | 一名赫奇帕奇一年级永久失联，3 条边断裂，02 学年一条交叉线永久关闭 |
| 17 | 圣诞 | ① 3 人礼物、送对 2 份 ② 处理隐形衣 | 一名斯莱特林被家族接走订婚，Rank 锁 7 到 04 学年 |
| 43 | 期末 | 考试 ≥A 且主线节点「魔法石」完成/改写 | 学年重读（行动点清零），或某人替你承担（欠「亏欠 5」一条边） |

## 5. 一次宫殿（第 01 学年第一座：斯内普）

### 5.1 时间线

```
第 3 周：走廊上第一次听到「地窖」的传闻（模型写，不算事件）
第 4 周：偶遇斯内普 → 她的 Rank 1 → 解锁「潜入门」情报
第 5–6 周：从她那里拿到第一块配方碎片
第 7 周：第一次进宫殿（1–2 层，打不过就撤）
第 8 周：第二次进（3–4 层 + 守门）
第 9 周前：改心完成 → 她 Rank 上限解到 10
```

### 5.2 一次完整 run（账）

| 步骤 | 玩家 | 资源变化 |
|---|---|---|
| 编队 | 哈利 + 罗娜 + 赫敏 + 阿利安娜（猫现形） | — |
| 第 1 层 | 探索 6 房、2 战、1 宝箱 | 灯火 220→150，HP 100→78 |
| 安全屋 | 存档 + 半恢复 | HP 78→89 |
| 第 2 层 | 3 房、1 精英、机关 | 灯火 150→70，HP 89→61 |
| 第 3 层 | 4 房、镜厅（碎片 1） | 灯火 70→0（全黑），警戒 12→34 |
| 第 4 层 | 守门 + 秘宝 | 警戒 34→61（判 −5） |
| 撤离 | 拿到 2 件残留 | 体力折回 61 → 62 |
| 改心 | 三条件齐 | Rank 上限 5→10 |

**这一次 run 占 2 行动点，换回**：1 件秘宝、1 块碎片、2 件残留、斯内普 Rank 可继续升。

### 5.3 打不过怎么办（闭合检查）

- 撤：进度保留（按层），下次从安全屋继续。
- 打不过守门：**可以先不打**，回去把她的 Rank 推到 5，拿「同行资格」再来。
- 完全放弃：宫殿每学年重组，下学年还能进，但她这一年不会改心（Rank 锁 5）。

## 6. 轮转：121 个人怎么都不消失

### 6.1 每周 4 席

| 席 | 规则 |
|---|---|
| A | 主群轮：12 群按周循环 |
| B | 主群轮的下一个群 |
| C | 玩家 Rank ≥5 的人里随机 1 个 |
| D | 本周事件相关（涨潮 / 群线 / 生日） |

- 12 群 × 每周 2 席 ≈ 6 周轮完一圈，一学年 7 圈。
- 每群 8–12 人 → **每人每年至少 1.5 次**。
- **连续 2 周不占席 → 第 3 周强制进 C 席**。

### 6.2 群像事件（每 3 周）

- 一次拉 8–12 人，写一场公共场面。
- 作用：让人同时在场 + 给两条支线牵动 + 补关系点。
- 一年 14 次，覆盖 121 人 ≥1 次。

### 6.3 软牵引

- 推进 A 的 Rank → A 的边上的 B、C 下周优先出现。
- 进宫殿带 A → 偶遇池偏向 A 的主群。

## 9. 单写原则（脚本分工）

| 字段 | 唯一写入方 | 谁只能读 |
|---|---|---|
| `/关系/{键}/Rank · 社群点` | 社群脚本 | 状态栏、网、宫殿 |
| `/关系/{键}/档案（16 项）` | 模型（首登场一次） | 状态栏 |
| `/五维/*` | 日程脚本 | 社群、检定、考试 |
| `/主角/体力·魔力·伤势·声望` | 检定 / 战斗脚本 | 模型（只读） |
| `/时空/*` `/日程/*` | 日程脚本 | 全部 |
| `/事件线索/*` `/期限/*` | 剧情脚本 | 状态栏 |
| `/宫殿/*` `/潜伏/*` | 宫殿脚本 | 前端 |
| `/秘密/*` | 秘密（并入剧情）脚本 | 模型写戏 |
| `/网/*` | 社群脚本（牵动） | 状态栏 |
| `/队伍/*` | 战斗脚本 | 前端 |

**违反 = 白名单拦截 + 回执 warn**。这条是 v10.1 唯一没做到、也是它烂掉的根本原因。

## 10. 出错与兜底（闭合判据 ③）

| 出错 | 兜底 |
|---|---|
| 模型写错枚举 | ZOD 夹回默认值，正文照出 |
| 模型漏写 `<affinity>` | 点数不涨，回执提示「这次没有结算」——不惩罚 |
| 模型自己写 `<check>` | 正则剥离 + warn |
| 模型写非法路径 | 白名单丢弃 + 回执「拦截 N 条」 |
| 闸门没过想硬过 | 拒绝 + 明确写「差什么」 |
| 行动点不够 | 拒绝 + 提示下一周 |
| 断网 / 前端加载失败 | MVU 报错卡；宫殿降级 ASCII；正文照出 |
| 全灭 / 被打出 | 撤退，不判死 |
| 逾期 | 不可逆，但世界伤之外都能补救 |
| 哈莉被发现 100 | 进「被带走」，行间可救回 |

## 11. 一条完整时间线（示例：第 5–9 周）

```
第 5 周：周三 陪罗娜（共情卡 4 阶）→ 周五 自习（共情 +1 → 5 阶）
        周六 未潜入（省点）→ 周日 短行动（递糖）→ 周结算
第 6 周：群像事件「魁地奇赌局」→ 认识奥莉芙、凯蒂、莉安
        周三 陪奥莉芙（Rank 1→2）→ 周六 潜入第 1 层（失败撤退）
第 7 周：周三 陪罗娜（社群点 78→88，Rank 9 门槛卡在共情 4 阶 → 停在 8）
        周五 采买（礼物 3 份）→ 周日 潜入宫殿 2 层 → 得到碎片 1
第 8 周：周三 陪德拉科娅（她的线第一次被拉进来）
        周六 潜入宫殿 3–4 层 → 守门 → 改心条件齐
第 9 周：万圣夜涨潮 → 提前完成（差 1 天）→ 奖励 1 件残留
        世界伤 0
```

**九周里发生了什么**：一条社群线走完两级、一个五维门槛过了、一座宫殿推进到改心、一场群像事件认识三个人、一次涨潮提前完成。**这就是"一周能做的事"的量级。**
