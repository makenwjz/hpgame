## 2. canon 要点（优先级 5）

- 主角 = **男版哈利**（0 愚者）；哈莉 = **平行世界来客**（21 世界），**没有宫殿**。
- **阿利安娜 = 13 死神**，序章入队，平时是**猫**（摩根娜位）。
- **德拉科娅 = 3 皇后**；**麦格 = 4 皇帝**；**卢娜 = 18 月亮**。
- **韦斯莱双子 = 8 力量**（一位两体）。
- 詹玛、莉莉、妮可、阿尔巴、格林德沃 **不可操作**。
- 巫师界**女女生育**：波特、马尔福、韦斯莱都是两位母亲。
- 初始队：哈利、罗娜、赫敏、阿利安娜。
