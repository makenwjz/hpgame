# 13 · 韦斯莱家：九个人，一条群像弧

> 用户要求：**韦斯莱家的孩子全部可攻略**。
> 这一份定两件事：**九个人怎么叠**（两个母亲 + 七个孩子）、**这一个家怎么变成玩法**。
> 规模规则见 `12-百人攻略与关系网.md`；马尔福家的同类写法见 `12` §5.1。

---

## 1. 先解决「九个人挤在一起」的问题

九个人若各写一条独立支线，读起来就是九张脸在同一栋房子里互相看不见。
所以韦斯莱家改用**家庭弧（Family Arc）**：

```
家主线：7 个阶段（与学年对齐）
   ↓ 每个阶段把「家里的一个决定」摆到三个以上的人面前
九个人不是九条线，是**同一件事的九个立场**
```

| 层 | 谁 | 作用 |
|---|---|---|
| **两位母亲** | 莫莉娅、阿蒂娅 | 定规矩、定钱、定这家的方向 |
| **六个孩子** | 珀西娅、芙蕾达、乔治娅、罗娜、金妮、萝茜 | 每人一个立场，互相咬 |
| **一个外来者** | 你 | 唯一能改变「这家人怎么商量事」的人 |

**核心设计**：韦斯莱家的痛点不是穷，是**「谁的话算数」**。
母亲说了算、珀西娅觉得自己最懂事、芙蕾达和乔治娅觉得这家的规矩是笑话、罗娜夹在中间、金妮最小所以没人听、萝茜还在长。**你帮谁说话，就决定了下一阶段谁有话语权。**

## 3. 九个人各自的门

### 3.1 莫莉娅（T2）
```
1 入口：第 1 周车厢里罗娜提到「我妈妈织了这个」
2 钥匙：她做的东西——毛衣、派、补过的袖口。夸她做得好不如吃完
3 雷区：说她「管得太多」；在她面前提钱
4 门槛：心志 3/5/7
5 收束：她把一件织了一半的东西塞给你，说「不高，你说不定不合身」
```
**她的真相**：她不是在管孩子，是在弥补自己二十岁时做的那个决定（那个决定把家留在了陋居）。

### 3.2 阿蒂娅（T2）
```
1 入口：魔法部下班、对角巷、或她来送忘带的午饭
2 钥匙：账本。她喜欢能用数字说话的人
3 雷区：说「你赚得不多吧」；浪费东西
4 门槛：共情 3/5/7
5 收束：她第一次不谈钱，谈她自己想做什么
```
**她的真相**：她本来能留在一间很好的办公室，她选了回家。

### 3.3 珀西娅（T2）
```
1 入口：第 2 周级长巡查；图书馆里她一个人占两张桌子
2 钥匙：让她「违规一次」——哪怕是抄近路
3 雷区：在别人面前说她是「家里的第二个妈」
4 门槛：学业 3/5/7
5 收束：她把徽章摘下来放进口袋，说「今天不算」
```
**她的真相**：她守规矩，是因为她觉得**只有规矩会记得她**。

### 3.4 芙蕾达（T1，太阳 19）
```
1 入口：第 1 周走廊上的爆炸声（无害的那种）
2 钥匙：她笑完之后的半句话。你要等
3 雷区：把她当小丑；只记住笑话忘了她
4 门槛：胆识 3/6/9
5 收束：她不笑了，说一件很认真的事
```
**双子的分线**：她与乔治娅共用塔罗 8 的一个操作位，但**攻略线是两条**，可以只推一条。

### 3.5 乔治娅（T1，与芙蕾达共 8）
```
1 入口：同上，但她会先看你有没有记住她的名字
2 钥匙：她被当成「其中一个」的次数
3 雷区：管她叫「芙蕾达」；夸她们「一模一样」
4 门槛：魅力 3/6/9
5 收束：她一个人来找你，没有姐姐
```

### 3.6 罗娜（T1，魔术师 1）
```
1 入口：第 1 周车厢；格兰芬多公共休息室织补旧袍
2 钥匙：家里的事——只能等她自己说
3 雷区：当众提她家穷；替她付钱
4 门槛：共情 3/6/9
5 收束：毕业前夜，球场看台，她把叠好的旧袍子递给你
```

### 3.7 金妮（T1，战车 7）
```
1 入口：第 3 周球场边；她一个人在练
2 钥匙：日记。第 02 学年之前不要碰这个话题
3 雷区：替她挡；叫她「小妹妹」
4 门槛：胆识 3/6/9
5 收束：她第一次在场上喊你的名字
```

### 3.8 萝茜（T3）
```
1 入口：一年级公共休息室；她哥哥姐姐的名字太重
2 钥匙：让她教你一件事
3 雷区：用「你姐姐怎样」开头
4 门槛：学业 2/4
5 收束：她把自己的笔记借给你，附一张纸条
```

### 3.9 荷格（T3）
```
1 入口：礼堂长桌；她总是先问别人吃不吃
2 钥匙：她自己——不是「罗娜的哥哥」
3 雷区：提「你家那么多人怎么吃饭」
4 门槛：心志 2/4
5 收束：她把最后一个鸡腿让给你，然后说这不代表什么
```

## 4. 家弧：七个阶段

**每个阶段 = 一个家里的决定**。所有九个人都在场（或通过别人转述在场），你选谁的话算数。

| 阶段 | 学年 | 家里的决定 | 站队 | 立刻后果 |
|---:|---:|---|---|---|
| 1 | 01 上 | 圣诞怎么过：全家回陋居，还是让孩子各自留下 | 莫莉娅（回）/ 珀西娅·罗娜（留） | 谁留下 → 谁的 Rank 5 提前 |
| 2 | 01 下 | 钱：阿蒂娅要不要接那份更远的工作 | 阿蒂娅（接）/ 莫莉娅（不接） | 接 → 经济宽裕，但阿蒂娅每月缺席；不接 → 家里更紧，莫莉娅点 + |
| 3 | 02 | 金妮的日记该不该给母亲看 | 莫莉娅（看）/ 金妮（别管）/ 你替她保管 | 影响 02 学年的密室线与金妮 Rank 上限 |
| 4 | 03 | 珀西娅毕业后是留校还是回家帮忙 | 珀西娅（走）/ 莫莉娅（回） | 走 → 珀西娅 Rank 7 提前；回 → 家规更稳，双子点 − |
| 5 | 04 | 双子的店：家里要不要出钱 | 出资（−钱）/ 不出（欠人情） | 出资 → 双子 Rank 10 解锁；不出 → 她们记你一次 |
| 6 | 05 | 罗娜要不要去当职业球员 | 支持 / 反对 / 不表态 | 三条走向，影响她 Rank 9 |
| 7 | 06 | 家宅：留还是卖 | 留 / 卖 / 翻修 | 决定第 07 学年的「家」还在不在 |

**规则**：每阶段只改 2–4 个人的状态，不改结构。**站错队不判死**，只是慢。

## 5. 三个叠层（不是一个一个来）

韦斯莱家的味道在于**同一件事同时被三个人理解成三件事**。所以每条 Rank 戏至少要拉一个第三人：

| 你的戏 | 必然牵动 | 例子 |
|---|---|---|
| 莫莉娅 | 罗娜 / 荷格 | 你夸毛衣，罗娜在旁边听见 |
| 阿蒂娅 | 珀西娅 | 钱的话题总会变成「谁懂事」 |
| 珀西娅 | 芙蕾达·乔治娅 | 她的规矩 vs 她们的笑话 |
| 芙蕾达 ↔ 乔治娅 | 彼此 + 罗娜 | 你叫错名字，三个人都记着 |
| 罗娜 | 金妮 | 姐姐在场时，她话变少 |
| 金妮 | 罗娜 / 莫莉娅 | 「最小的那个」 |
| 萝茜 / 荷格 | 全家 | 被当成小孩 |

**技术口径**：不新增变量。用 `/网/{A}▸{B}` 记牵动，写出以 `12` §6 的边规则为准。

## 6. 家族知情度（复用马尔福家的规则）

```
知情度 = 0     九人中无人 Rank ≥4
       = 30    一人 ≥4
       = 60    三人 ≥6
       = 90    五人 ≥6
       = 100   七人 ≥6
```

| 知情度 | 状态 |
|---:|---|
| 0–29 | 各自不知道 |
| 30–59 | 知道了，饭桌上没人提 |
| 60–89 | 荷格会当众问「你是不是在跟两个姐姐好」（全场安静） |
| 90–99 | 莫莉娅找你谈话：「我不在乎你跟谁，我在乎你有没有骗」 |
| 100 | 群像事件 **「陋居的餐桌」**：九人同场，各 +8；家庭弧进度 +1 |

**和马尔福家一样的唯一硬规则**：**不能骗**。同时答应两人 → 三人一起掉点；但**九个人可以同时推进**，没有一个会因为别人而关门。

## 7. 「孩子太多」怎么不让它变成负担

三条：

1. **同场写法**：韦斯莱家的戏默认 2–3 人同框，不单独开房间。罗娜的戏，荷格在楼下；珀西娅的戏，双子在门外笑。
2. **轮转**：每周 4 席里，韦斯莱家的席位固定 1 个（按「主群轮」），保证这家人**永远有人在**。
3. **群像事件**：每个家庭弧阶段配一场全家戏（餐桌、圣诞、球场），一次把九个人都点亮，防止有人整年不出现。

## 10. 一句话

韦斯莱家不是一个「很多攻略对象的房子」，是**一张餐桌**。
你坐进去，谁给你盛饭、谁问你今天怎么样、谁在桌子底下踢你，就已经说明了所有关系。
