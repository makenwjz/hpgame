## 3. ⚠️ 推送失败：需要你补一步

**现象**

```
git clone  → 成功（能读）
git push   → TLS connect error / could not read Username
```

**原因**：本机 `git` 只有匿名读权限，没有 GitHub 凭据；沙箱内无法交互输入。

**你需要做的（三选一）**

1. **最省事**：你在本机终端里执行
   ```bash
   cd "C:\bd\ds project"
   git push -u origin main
   ```
   弹出登录时用浏览器授权即可（本地 commit 已在，推上去就是全部）。
2. **用 token**：在仓库 Settings → Developer settings 生成 Personal Access Token（`repo` 权限），然后
   ```bash
   git remote set-url origin https://<TOKEN>@github.com/makenwjz/hpgame.git
   git push -u origin main
   ```
   推完建议改回原 URL，别把 token 留在配置里。
3. **用 SSH**：配置好 key 后
   ```bash
   git remote set-url origin git@github.com:makenwjz/hpgame.git
   git push -u origin main
   ```

**推送成功后告诉我，我再继续写 `src/` 与 `tools/`。**
