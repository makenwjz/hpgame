# 10 · 战斗：八方旅人式

> 本文件是宫殿战斗的**唯一权威**，覆盖 `06-宫殿JRPG.md` §7。
> 探索层见 `06-宫殿像素探索.md`，角色与职业见 `08-二十二塔罗.md`，宫殿见 `07-九宫殿.md`。

---

## 1. 为什么是八方

Persona 的「1 More」是回合内连动，爽但浅；八方的三层咬合更适合长线卡：

| 层 | 机制 | 玩家在想什么 |
|---|---|---|
| 表层 | **护盾 + 弱点** | 先试出弱点，再决定谁去削盾 |
| 中层 | **BP 增幅** | 这一点攒着打 Break，还是现在就打 |
| 深层 | **行动队列** | 谁先动、Break 能维持几回合 |

三件事叠在一起，才有「这一回合我算对了」的快感。
**因此取消 1 More**——连动会让 Break 的价值塌掉。

---

## 2. 回合流程

```
① 回合开始：状态结算；全员 BP +1（上限 5）
② 按 SPD 排行动队列（显示本回合与下回合）
③ 每个单位行动：攻击 / 技能 / 道具 / 防御 / 逃跑
④ 结算：命中 → 伤害 → 弱点削盾 → 是否 Break
⑤ Break 单位跳过本回合剩余行动
⑥ 回合结束：状态倒计时，Break 恢复（下回合可行动）
```

**行动队列必须显示**：玩家要能看见「敌人下一动是谁」，才谈得上算。

---

## 3. BP（Boost Point）

| 项 | 规则 |
|---|---|
| 初始 | 1；Boss 战 3 |
| 每回合 | +1，上限 **5** |
| 单次最多投入 | **3** |
| 不消耗 | 防御、逃跑不消耗 BP |

**增幅效果**

| 行动类型 | BP1 | BP2 | BP3 |
|---|---|---|---|
| 物理攻击 | +1 段（每段 70%） | +2 段 | +3 段 |
| 魔法 | 伤害 ×1.5 | ×2.0 | ×2.5 |
| 道具 | 目标 +1 | 全体 | 全体且效果 ×1.5 |
| 防御 | 减伤 50% | 60% + 先手 | 70% + 先手 + 下回合 BP +1 |

**段数伤害**：每段按 70% 计算，所以 BP3 物理 ≈ 2.8 段等效，**不是 4 倍**——增幅是节奏工具，不是核弹。

---

## 4. 护盾与弱点

| 项 | 规则 |
|---|---|
| 护盾 | 敌人 1–5 点 |
| 削盾 | **只有命中弱点才 −1**（普攻/技能都算，一段只削 1） |
| 弱点未知 | 显示 `?`；命中一次即揭示该属性 |
| 揭示手段 | 学者「识破」可直接揭示 1 个；菲伦萨被动开局显示 1 个 |
| 弱点数量 | 普通 1–2，精英 2，Boss 每阶段 2–3 |

**注意**：弱点**不直接加伤害**（这是与 Persona 最大的区别）。
它只做一件事——**削盾**。伤害要靠 Break 换。

---

## 5. Break

护盾归零 → 该敌人 **Break**：

```
· 本回合剩余行动全部取消
· 下一回合也无法行动
· 期间受伤 ×2.0，DEF / RES 视为 0
· Break 结束时护盾回满，弱点重置为未知（Boss 除外）
```

**Break 是唯一的爆发窗口**。一切 build 都围绕「在 Break 的两回合里把伤害打进去」。

**合围**（全队同时 Break 全部敌人）：额外获得 1 次全员免费行动，且必掉一个宝箱。

---

## 6. 伤害

```
物理 = max(1, floor((ATK × 2 − DEF) × 段数系数 × BP系数 × Break × 浮动 × 暴击))
魔法 = max(1, floor((MAG × 2 − RES) × BP系数 × Break × 浮动 × 暴击))
```

| 项 | 值 |
|---|---|
| 浮动 | 0.9–1.1 |
| 暴击 | 5% + LUK/10 %，×1.5 |
| Break | ×2.0 |
| 防御 | ×0.5 |
| 属性抗性 | 弱 1.0 / 普通 1.0 / 抗 0.5 / 免疫 0 |

**七属性**：火 / 冰 / 雷 / 风 / 光 / 暗 / 物理。

> 属性只在**削盾**上有意义，伤害倍率上不区分强弱——这样玩家不需要背两套表。

---

## 7. 行动队列与速度

- 排序：SPD + 随机 0–3。
- 提速/减速技能改的是 SPD，不直接改队列位置（下一回合生效）。
- 防御：本回合减伤，且下回合行动提前 3 点。
- 逃跑：50% + SPD 差 ×5%；失败浪费一回合。

**Boss 不显示具体 SPD**，只显示队列头像——留一点不确定性。

## 8. 八个职业与 JP

每个角色一个职业，**没有副职业**（22 人已经够复杂）。

| 职业 | 武器 | 技能（学一级花 JP） |
|---|---|---|
| 剑士 | 剑 / 长柄 | 强斩 0 / 三连斩 30 / 挑衅 80 / 盾击 200 / 破甲 500 / 十字斩 1000 |
| 黑魔 | 杖 | 火焰 0 / 冰锥 30 / 雷击 80 / 吸魔 200 / 爆炎 500 / 陨石 1000 |
| 白魔 | 杖 / 锤 | 治愈 0 / 群体治愈 30 / 净化 80 / 守护 200 / 复活 500 / 圣光 1000 |
| 学者 | 书 | 识破 0 / 减速 30 / 封印 80 / 解析 200 / 弱点共享 500 / 时停 1000 |
| 盗贼 | 短剑 | 偷袭 0 / 偷窃 30 / 烟雾 80 / 二连 200 / 背刺 500 / 影分身 1000 |
| 猎人 | 弓 | 瞄准 0 / 陷阱 30 / 乱射 80 / 鹰眼 200 / 贯穿 500 / 万箭 1000 |
| 诗人 | 乐器 | 鼓舞 0 / 安魂 30 / 魅惑 80 / 加速曲 200 / 镇魂歌 500 / 终曲 1000 |
| 炼金 | 瓶 | 调和 0 / 酸液 30 / 爆炸 80 / 强化 200 / 转化 500 / 贤者之石 1000 |

- JP 来源：普通战 3–8，精英 15–25，Boss 80–150。
- 满一个职业约需 **3–4 座宫殿**。
- **奥义**：技能树最后一项（1000 JP），需要 BP 3 才能发动。

## 10. 敌人与 Boss

### 10.1 敌人模板

| 类型 | HP | 护盾 | 弱点 | 备注 |
|---|---:|---:|---|---|
| 杂兵 | 40–80 | 1–2 | 1–2 | 2 回合解决 |
| 精英 | 150–260 | 2–3 | 2 | 需要一次 Break |
| 认知存在 | 300–500 | 3 | 2 | 宫殿中层 |
| Boss | 1,200–2,500 | 3/4/5 | 2–3 | 三阶段 |

### 10.2 Boss 三阶段

```
阶段一 100–60%：护盾 3，弱点 A/B
阶段二 60–30%：护盾 4，弱点 B/C，换招式表
阶段三 30–0%：护盾 5，弱点 C/A，进入「狂暴」每回合攻击两次
```

**切阶段暂停战斗**，交给模型写 2–4 段对峙戏；戏写完再继续。
**禁止**模型描述具体伤害数字——它只拿摘要。

### 10.3 全灭

全员战斗不能 → 撤退：碎片全失，体力 −20，伤势 +20，警戒 +25。
**不写「游戏结束」。**

## 11. 与探索层的接口

| 探索层 | 战斗层 |
|---|---|
| 明雷 / 暗雷 | 进入战斗，按接触方向定先制 |
| 地形（火/水/冰/黑暗） | 对应属性 +10% / 命中 −10% |
| 灯火 0 | 全队命中 −10%，敌方先制 |
| 警戒 ≥60 | 敌方 ATK +10% |
| 安全屋 | 半恢复 + 存档 + 换人 |

**探索层不参战，战斗层不改地图。**

## 12. 平衡基准

| 项 | 值 |
|---|---|
| 普通战 | 2–4 回合 |
| 精英战 | 4–6 回合 |
| Boss | 12–20 回合 |
| 一层消耗 | HP 30–50%，MP 40% |
| 一次 Break 窗口 | 2 回合，伤害约占总量的 40% |
| 一件装备 | ATK/DEF +5~25 |
| 一座 5 层宫殿 | 40–60 分钟，分 2–3 次潜入 |

## 13. 与旧 JRPG 版的差异

| 项 | 旧（`06-宫殿JRPG` §7） | 本版（八方） |
|---|---|---|
| 弱点 | 伤害 ×1.5 | **只削盾，不加伤** |
| 连动 | 1 More | **取消** |
| 爆发 | 护盾 Break ×1.5 | **Break ×2.0 + 防御归零** |
| 队列 | 无 | **显示本回合 + 下回合** |
| 增幅 | BP 加伤害/段数 | **段数 70%/段，节奏工具** |
| 职业 | 8 职业 | 8 职业 + JP 技能树 + 奥义 |

一句话：**从「打弱点加成」改成「削盾换窗口」**。这是八方的手感，也是唯一能让 BP 有意义的结构。
