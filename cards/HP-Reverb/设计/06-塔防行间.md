# 06 · 行间改成塔防

> 本文件取代 `03-行间对峙回声.md` 的 §2–§7、§11（节点图与部位制）。
> 03 的**对峙公式、回声、深线、守护神**继续有效；变的只是「一局怎么摆开」。

## 1. 先回答：塔防我熟，能偷的东西很多

| 游戏 | 偷什么 | 用在本卡哪里 |

| **明日方舟** | 部署费（DP）、阻挡数、技能轴、波次预告 | 意志＝DP；同伴＝挡 1 的地面单位 |

| **地牢迷踪** | 守核心 + 房间探索 + 肉鸽 | 「守门」而不是「推塔」 |

**为什么这张卡适合塔防**：霍格沃茨的走廊、楼梯、管道本来就是天然的「路」；行间按记忆重组，所以每局地图都不一样；敌人类型（蛇、摄魂怪、博格特、亡灵、巨人、痴愚）早就写好了弱点——**塔防要的东西，v10.1 的设定里全有，只是没人把它们摆成一张图。**

## 2. 核心转变：从「走节点」到「守一条路」

**旧版**：5 重 × 4–6 部位，玩家选路，逐个结算。
**新版**：一次潜入 = **一张地图 × 5 波 + 1 首领波**。敌人从走廊尽头进来，你在这头把术式、同伴、造物摆上，守住「门」。

- **门**不是要攻下的目标，是**你的退路**。
- 漏一只，回声就涨；涨到 100，门塌，你被打出。
- 所以塔防的失败不是「打不过」，是「放进来太多」。

一句话：**这不是塔防，这是用塔防的方式做「你能承受多少」的算术。**

## 3. 战场

### 3.1 棋盘

```
出口                                                        入口
 门 ◀── 列6 ── 列5 ── 列4 ── 列3 ── 列2 ── 列1 ── 敌人生成
        ▲      ▲      ▲      ▲
      可部署  可部署  可部署  可部署
```

- **3 条路**：左廊 / 中庭 / 右廊。
- **6 列**：敌人从列 1 生成，走到列 6 的门。
- **可部署格**：每路列 2–5，共 **12 格**。
- 敌人 **1 tick 走 1 格**；被阻挡则停下互殴。
- 每波 **6 tick**。

### 3.2 射程

| 射程 | 含义 |
|---|---|
| 1 | 同路相邻格 |
| 2 | 同路 ±2 格 |
| 3 | 同路 ±3 格，或邻路 ±1 格 |

## 4. 六种防守单位

部署费＝**意志**（局内货币）。

| 单位 | 费 | 攻/tick | 射程 | 阻挡 | 特性 | 弱点加成 |
|---|---:|---:|---:|---:|---|---|
| **焚**（火） | 6 | 10 | 2 | 0 | 单体 | 蛇类 / 亡灵 ×1.5 |
| **缚**（冰） | 7 | 5 | 2 | 0 | 减速 1 tick | 巨人 ×1.5（石化） |
| **守**（护） | 8 | 0 | 3 | 0 | 治疗友方 4/tick；**唯一能伤摄魂怪** | — |
| **识**（秘） | 9 | 8 | 3 | 0 | 同时打 3 个目标 | 痴愚 ×1.5；无视护甲 |
| **役**（造物） | 3 | 4 | 1 | 1 | 便宜的血包 | — |
| **同伴** | 8 | 10 | 1 | 1 | HP 40；带支援技能（Rank 5 起） | 按人物 |

**升级**：每个单位可升 2 级，费用 4 / 8，攻 +50% / +100%，射程 +1（第三级）。

### 4.1 术式的两条专精（二选一，不可洗）

| 单位 | 专精 A | 专精 B |
|---|---|---|
| 焚 | **燎原**：命中后溅射同格 | **熔心**：对单目标 +80% |
| 缚 | **霜锁**：减速 2 tick | **碎冰**：被冻住的受 +50% 伤害 |
| 守 | **庇**：治疗量 ×2 | **圣**：摄魂怪伤害 +100% |
| 识 | **洞见**：打 5 个目标 | **穿刺**：无视护甲且 +30% 对巨人 |

## 6. 一局的经济

| 项 | 值 |
|---|---|
| 初始意志（DP） | **10** |
| 每波结束 | +3 |
| 击杀奖励 | 每 3 个敌人 +1（本波结算） |
| 上限 | 20 |
| 撤退返还 | 不返还 |

**意志不能带出**——花不完就是浪费。

## 7. 波次与「领会」

每局固定 **5 波 + 1 首领波**。

```
部署阶段（花 DP 摆单位、升级、用技能）
   ↓
波次结算（脚本模拟 6 tick，输出报告）
   ↓
清空 → 三选一「领会」
   ↓
下一波
```

**波间三选一**（每波必给，这是肉鸽的核心）：

| 类别 | 例 |
|---|---|
| 新蓝图 | 解锁「识」或「缚」（开局只有焚 / 役 / 守） |
| 强化 | 某一座塔免费 +1 级 / 全体攻 +10% |
| 残留 | 一件被动（见 §8） |
| 资源 | +6 意志 / +1 波次容量 |

**首领波**：不打完也能过——撑过 6 tick 就算守住，但拿不到核心残留。

## 8. 残留（肉鸽遗物）

| 类别 | 效果 |
|---|---|
| 部署 | 初始意志 +3；首个单位免费 |
| 火力 | 焚/识 攻 +20%；对空（飞行系）伤害 +30% |
| 控制 | 缚的减速 +1 tick |
| 生存 | 守的治疗 +2；同伴 HP +15 |
| 经济 | 每波 +1 意志 |
| 改图 | 开局可挪动一个可部署格（改写路径） |
| 一次性 | 重掷一波 / 撤销一次部署 |

**合成**：三件同类残留可合一件强化版（宝石争霸那套）。上限 7 件，带出 ≤ 到达波次 ÷ 2（向上取整）。

## 9. 回声

| 事件 | 回声 |
|---|---:|
| 漏一只 | **+15** |
| 首领波被破门 | +20 |
| 主动大招（守护神 / 时间） | +10 / +15 |
| 用「重掷」残留 | +5 |
| 清波无漏 | −3 |

| 档 | 效果 |
|---|---|
| 0–39 | 无 |
| 40–59 | 偶遇变凶 |
| 60–79 | 所有单位攻 −10%；行商涨价 |
| 80–99 | 敌人 HP +20%；门开始响 |
| 100 | 门塌：被打出 |

**被打出**：残留减半，触发一次不可逆后果（断边 / 某人受伤 / 期限提前一周）。

## 10. 六张地图（由「门」决定）

门不再给 buff，**门就是地图**。

| 门 | 地图 | 特征 | 首领 |
|---|---|---|---|
| 大厅门 | 礼堂长廊 | 三路笔直，格多，适合新手 | 巨怪 |
| 厨房门 | 地下管道 | 单路宽，敌人快，AoE 有利 | 蛇王 |
| 钟楼门 | 旋转楼梯 | 之字形，敌人换道两次 | 时间残影 |
| 湖底门 | 淹没回廊 | 窄，只有 6 格，减速流 | 水鬼 |
| 画像门 | 会动的走廊 | 每波随机封锁 2 格 | 画中人 |
| 有求必应屋门 | 自造空间 | 开局自选布局，回声 +5 | 你自己 |

**深线归属**：每张图挂一条深线（生 / 死 / 时 / 空），守门人即该深线守门人。打穿首领 → 核心残留 +3 深线值。

## 11. 与其它系统的接口

| 系统 | 接口 |
|---|---|
| 行动点 | 潜入 = 2 点（周六 + 周日） |
| 体力 | 每波 −5；被打出额外 −25 |
| 魔力 | 技能消耗；每波回 10 |
| 同行 | 每个同行 = 一张可部署的「同伴」卡（不用 DP 招募，但要占格） |
| 支援 | Rank 5 / 8 / 10 = 同伴卡 Lv1 / Lv2 / 技能解锁 |
| 五维 | 不直接加成；胆识 ≥4 时，开局多 2 意志（叙事：你敢来） |
| 社群 | 不带进本的人也能「远程支援」：Rank 6+ 每人给 1 点初始意志 |
| 网 | A×B 边 ≥3 且两人都在同行 → 合击：一波一次全屏伤害 |
| 深线 | 首领核心残留 → 深线值 +3 |
| 秘密 | 哈莉同行时，发现度机制仍然生效（见 07） |

## 12. 一局走一遍（数值）

```
周六，<act do="潜入" door="钟楼门"/>    ← 2 点
地图：旋转楼梯（3 路 × 6 列，之字换道）
初始：意志 10，回声 0，体力 100，同行：罗娜 + 哈莉

部署：缚(7) 中列3 → 焚(6) 左列4 → 意志 10-13 = 负 → 只能先摆一个
  实际：缚(7) 中列3，剩 3；役(3) 右列2 当阻挡，剩 0

第 1 波（蛇 ×3）：缚减速 + 役挡 1 → 漏 0，回声 0−3 = 0（下限）
  结算：意志 +3，领会三选一 → 拿「焚 蓝图」（免费）

第 2 波（蛇 ×4）：摆焚，漏 1，回声 +15
第 3 波（摄魂 ×3）：只有守能伤，没守 → 只能靠役挡 + 硬吃，漏 2，回声 45
第 4 波（巨人 ×1 痴愚 ×2）：识未解锁，巨人打不动，漏 1，回声 60
第 5 波（混编 5）：玩家选择主动撤离（不等首领）
  带出：到达第 5 波 → 残留下限 7 件，实得 3 件
  深线「时」+1；体力 100→75；回声清零
```

**这一局的账**：2 行动点换 3 件残留 + 一次深线推进 + 一次「我该早点撤」的后悔。
**下一次她会带守。**——这就是塔防 + 肉鸽的学习曲线。

## 13. 脚本接口

```
<deploy unit="焚" lane="中" col="3" mastery="熔心"/>
<deploy unit="同伴" who="罗娜·韦斯莱" lane="左" col="2"/>
<upgrade lane="中" col="3"/>
<wave/>                       ← 触发 6 tick 模拟
<skill name="守护神"/>
<retreat/>
```

脚本输出（折叠在正文里，不占叙事）：

```
<defense wave="3" leak="0" dp="6" echo="18" kills="4"/>
```

模型只负责把这些数字写成戏。

**禁止**：模型自己宣布「漏了 0 只」或「全歼」。数字只由脚本给。

## 14. 平衡基线（验收用）

| 波 | 敌人 | 期望漏 | 期望回声 |
|---:|---|---:|---:|
| 1 | 3 只普通 | 0 | 0 |
| 2 | 4 只普通 | 0–1 | 0–15 |
| 3 | 3 只摄魂 + 2 普通 | 1 | 15–30 |
| 4 | 1 巨人 + 2 痴愚 | 1–2 | 30–45 |
| 5 | 混编 6 只 | 1–2 | 45–60 |
| 首领 | 1 首领 + 4 小 | 看配置 | 60–80 |

**设计红线**：一个「只摆一种塔」的玩家，应该在第三波就卡死；一个「读懂弱点」的玩家，应该能在第五波前把回声压在 40 以下。两者差距就是这套系统的深度。

```
│ 意志 6/20   回声 18 ▓▓░░░░░   体力 85   │
│ 左廊  [ ] [焚2] [ ] [ ]  →门           │
│ 中庭  [ ] [ ] [缚1] [役]  →门           │
│ 右廊  [ ] [ ] [ ] [ ]     →门           │

```

「下一波预告」是塔防最关键的信息，必须常显。
