# 19 · 环境探针（第 1 步）

> 目的：**在写任何业务代码之前，先确认这台机器能做什么。**
> 8 项探测，每一项决定后面一条路线是"能走"还是"要改"。
> 全部只读、不写你的变量、不改你的聊天记录，跑完点一下面板就关掉。

---

## 1. 文件

| 文件 | 作用 |
|---|---|
| `probe/probe.mjs` | 一个 3 行 ES 模块，用来测「能不能从 GitHub 加载远程模块」 |
| `probe/probe-script.js` | 酒馆助手脚本，跑 8 项探测，结果打面板 |

两个都已推到 `main`。

---

## 2. 怎么装（3 分钟）

### 方式 A：手动导入脚本（一定能用）

1. 打开 SillyTavern，进入任意聊天
2. 右侧图标栏点开**酒馆助手**
3. 找到「**脚本库**」（或「脚本管理」）→ 新建脚本
4. 名字填 `HP-Reverb 探针`
5. 把 `probe/probe-script.js` 的**全部内容**粘贴进去
6. 保存 → 启用
7. 切一次聊天（或刷新页面），让它重新加载

### 方式 B：从网址导入（顺便验证「脚本库能否按 URL 导入」）

如果酒馆助手有「**从 URL 导入**」按钮，直接填：

```
https://raw.githubusercontent.com/makenwjz/hpgame/main/probe/probe-script.js
```

**能导入 = 第 ① 项通过；导不进来，就用方式 A，同时记下"URL 导入不可用"。**

## 4. 八项分别决定什么

| # | 探测项 | 通过 | 不通过 |
|---:|---|---|---|
| 1 | ST 与酒馆助手版本 | 记下版本号，后面全按它写 | — |
| 2 | **远程 ES 模块 import** | 可以"代码放 GitHub、卡里只留引导" | 退到「内置快照 + 手动更新」 |
| 3 | fetch 远程文件 | 可以下载数据表（121 人 / 宫殿） | 数据表必须打包进卡 |
| 4 | localStorage | 可作为离线缓存 | 只依赖 MVU |
| 5 | IndexedDB | 可缓存多个版本、可回滚 | 只留当前一版 |
| 6 | MVU 可用 | 变量系统能跑 | **整张卡不成立**，先装 MVU |
| 7 | 酒馆助手变量接口 | 读写变量 | 同上 |
| 8 | 事件系统 | 能监听消息/切聊天 | 只能靠模型主动触发 |

**其中第 2、3、6 项是决定性的。**

```
2 ✅ 3 ❌       → 代码远程、数据表进卡（混合）

```

## 6. 安全说明

- 探针**不读**你的聊天记录、**不写**你的变量、**不上传**任何东西。
- 只做三件事：读版本号、尝试加载一个 3 行的公开模块、测试本机存储能否写入（写完立刻删）。
- 测试用的键名是 `__hp_probe` / `__hp_probe_panel`，跑完即清。

---

## 7. 如果面板没弹出来

说明脚本没被加载或提前出错。检查：

1. 酒馆助手里那个脚本是不是**启用**状态
2. 控制台有没有 `[probe]` 开头的日志
3. 有没有 `ReferenceError` —— 把报错原文发我
