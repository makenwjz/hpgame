# 02 · 社群（Rank 1–10）与网

> 两个模块合在一份：**社群是纵向**（一个人十级台阶），**网是横向**（人和人之间那根线）。
> 刻度见 `00-总纲与契约.md` §2；时间与行动点见 `01`。

---

## 1. 一条社群是什么

一个可攻略的人 = 一条社群 = **Rank 1–10 + 点数 0–100**。

- `Rank = 1 + floor(点数 ÷ 10)`，但**升级要过门槛**（见 §3）。
- 点数只由 `<affinity>` 结算，模型不得直接写 Rank。
- 不联系不掉点。冷淡不是惩罚，只是不涨。
- 龙套不建社群，给一个固定态度（亲近 / 中立 / 戒备 / 敌意）。

**为什么不是五档羁绊**：五档只够写「关系变了」，十档才够「每一级都给东西」。Persona 的手感全在「这一级解锁了什么」。

## 2. 点数的加减

| kind | delta | 说明 |
|---|---:|---|
| 对话 | +2 | 短行动级别：递一句话、打个招呼、一起走一段 |
| 帮助 | +8 | 帮成一件具体的事（有风险、有代价、被看见） |
| 送礼 | +5 | 送对 +8，送错 −3；生日 ×2 |
| 共患难 | +10 | 一起挨罚、一起夜探、一起被卷进麻烦 |
| 检定 | +5 | 一次检定她看在眼里（成功 +5，失败 +3——她看见你敢上） |
| 任务 | +10 | 完成她的某一步支线或关键选择 |

**硬帽**：单次 ≤10，单周同一个人 ≤2 次结算，一周内第二次 ×0.5。

**减分**

| 行为 | delta |
|---|---:|
| 冒犯 / 说错话 | −5 |
| 失约 / 放她鸽子 | −8 |
| 碰到她在意的东西（伤疤、家人、旧事） | −10 |
| 背叛 / 当众伤她 | −20，并可能断网边 |

**衰减**：同一 `kind` 连续三次（如连续三次「帮助」）→ 第三次起 ×0.7。她不是任务板。

## 3. 升级流程（脚本五步）

```
① 名单校验：不在 64 人名单 → 不结算，只记 warn
② 幅度夹取：按 kind 定档，夹进单次上限 10，再按周内次数打折
③ 点数结算：/关系/{键}/社群点 += delta，夹 0–100
④ 门槛校验：新 Rank = 1+floor(点/10)
   ├─ 未过门槛 → Rank 不动，点数照涨，回执写「她愿意再走近一步，但你还差点什么」
   └─ 过门槛   → Rank +1，进入 ⑤
⑤ 升级兑现：触发一场 Rank 戏 → 发该级奖励 → 写 /社群事件台账
```

**Rank 10 的额外条件**：点数满 100，且**任意三维 ≥4 阶**。

**Rank 不会掉**。掉的只有网边的强度与「恋」的资格。

## 4. 十级台阶：每级给什么

| Rank | 名字 | 戏眼（通用骨架，人设里替换成她的具体事） | 奖励 |
|---:|---|---|---|
| 1 | 认得你 | 一场有内容的对话，她记住你的名字 | 建立社群，人物页出现 |
| 2 | 她记得你 | 一件小事：她替你留了位子 / 记得你怕什么 | **情报**：一条只对你说的小道消息（网边 +1 或解锁一个地点） |
| 3 | 试探 | 她开始问你问题，也躲一个 | **专属行动**：借笔记 / 进准备室 / 用球场 / 蹭课 |
| 4 | 交底半步 | 她讲一件私事，讲一半 | **网边 +1**，或解锁她的公共场子 |
| 5 | 并肩 | 一起做成一件有风险的事 | **同行资格**：可带进行间，支援 Lv1 |
| 6 | 站队 | 她在两难里选了你，或你替她挡了一次 | **专属能力**：一条咒语 / 一张配方 / 一件道具 |
| 7 | 裂痕 | 一次真正的冲突，你选错就退半步 | **隐秘边显形**（暗恋 / 把柄 / 共谋） |
| 8 | 托付 | 她把某样东西交给你保管 | **支援 Lv2** + 三角冲突解锁 |
| 9 | 选择 | 她问你要不要越界 | **「恋」分支开放**（**不排他**，可多条并行）+ 关键道具 |
| 10 | 结局 | 她的个人结局线 | **支援 Lv3** + 终局钥匙 |

### 4.1 Rank 戏的三条写法

1. **一场戏只解决一件事**：一个决定、一次坦白、一次沉默。不要在一场戏里塞两级。
2. **结尾留记号**：一件东西 / 一句话 / 一个称呼 / 一次共同的沉默。写进 `当前任务`。
3. **不替她解决**：你只能看见，不能替她做。她的人生不是你的支线奖励。

### 4.2 「当前任务」字段怎么写

```
旧袍子｜下一级 rank 3 要共情 3 阶
```
格式：`戏眼｜下一级缺什么`。状态栏直接显示这一行，玩家一眼看到「卡在哪儿」。

## 5. 门槛：她最看重的那一维

每人在 `社群事件表` 里定死一维，写进人设【关系网】段上方。

| Rank | 门槛 |
|---:|---|
| 3 | 该维 ≥3 阶 |
| 6 | 该维 ≥4 阶 |
| 9 | 该维 ≥5 阶 |
| 10 | 任意三维 ≥4 阶 + 100 点 |

卡住时的叙事口径（唯一写法，别处不许改）：
> 她愿意再走近一步，但你还差点什么。

**「差点什么」不许点破**。玩家自己回去看五维页。

## 6. 三角冲突

触发：A、B 同场，且双方 Rank ≥4，且 A×B 的边是「对立」或「紧张」。

```
① 场景里两人同时在场
② 出现一个必须选边的事件（不是选择题，是情境）
③ 玩家选择 / 不选
   ├─ 选 A：B 的 Rank 上限锁 7（不清零），A 的边 +1，B 的边 −1
   ├─ 选 B：对称
   └─ 不选：双方上限各锁 8，但 A×B 的边强度 +1（她们自己解决了，你被排除在外）
④ 锁上限只持续到 B 的 Rank 9 事件——那场戏里可以解锁（要付代价）
```

**为什么锁 7 而不是清零**：清零是惩罚，锁 7 是「你们还能做朋友，但到不了那一步」。后者才有余味。

## 8. 首次登场的档案

触发：第一次有实质对话。

**同一次 Patch 里写全 16 项**（不写「未知」，没写就是没写，状态栏整格跳过）：

| 组 | 字段 |
|---|---|
| 身份 | 年龄 / 身份 / 出身 / 服饰 / 印象 |
| 形体 | 身高 / 体重 / 三围 / 体型 / 身体 |
| 私密 | 名器评级 / 名器（**首次性行为之后才写**，此前留空） |
| 关系 | 当前任务 |

`服饰` 一句：颜色、料子、配件、磨损。
`印象` 一句：别人第一眼会怎么读她。
`身体` 一句：肤色、发质、眼睛、手脚细节。

**服装六项**（常服 / 校服 / 礼服 / 内衣 / 鞋袜 / 饰品）同批写，此后只有真换装才改。

不是所有核心节点都能「约出来」。这四类走特殊口径，避免脚本按普通人结算：

| 节点 | 类型 | 推进方式 | Rank 上限 | 恋 |
|---|---|---|---:|---|
| 詹玛·波特 | 已故 | 遗物、信、墓前、别人的回忆；用「追忆」短行动（1 点） | 7 | 无 |
| 莉莉·波特 | 已故 | 同上 | 7 | 无 |
| 阿利安娜·邓布利多 | 已故 | 画像、日记、邓布利多的叙述 | 7 | 无 |
| 海伦娜·拉文克劳 | 幽灵 | 走廊偶遇、夜谈；不写身体与服装档案 | 7 | 无 |

| 格林德沃 | 囚徒 | 只能行间接触；**无 Rank**，用深线值代替 | — | 无 |

## 8.6 关系结构：不排他（定稿）

**全卡不设「只能选一个」的硬锁。** 多条「恋」可以并行推进。

| 项 | 规则 |
|---|---|
| 并行上限 | 同时开着的「恋」≤ **5 条**（再多就不再是克制，是流水线） |
| 不关别人的门 | A 开了恋，B 的 Rank 9/10 不受影响 |
| 唯一硬约束 | **不能骗**：同一周里答应两个人的事 → 两人各 −15，且 3 周内不再接受同一类承诺 |
| 知情度 | 家族 / 团体内部按 `12` §5.1 的规则推导（马尔福家 3 人、韦斯莱家 9 人各一套） |
| 被发现 | 知情度 ≥60 后，任何一次「同时承诺」都算欺骗；但**坦白不算** |
| 终局 | 每条恋各给一个个人结局；多个恋同时成立时，第 07 学年会追加一场「怎么安排」的群像戏 |

**为什么不排他**：这张卡的 121 个人分布在大约 20 个生活圈里，她们本来就不同时在同一条走廊上。
强行排他只会让玩家在最后一周才敢碰别人——那是流程设计的问题，不是玩家的问题。

**唯一需要玩家付代价的地方**：时间和信用。时间不够见完，信用不够骗第二次。

## 9. 网

### 9.1 边的六种类型

| 类型 | 含义 | 玩法咬合 |
|---|---|---|
| 血脉 | 家族、继承、同门 | 影响学院立场与初始态度 |
| 师承 | 师生、学徒 | 课程 / 咒语传授，行间支援连携 |
| 同盟 | 共同目标 | 可同时带进行间，支援叠加 |
| 对立 | 竞争、仇怨 | 同场扣支援，触发选边 |
| 亏欠 | 人情、救命恩 | 可强制发动一次求助，消耗边强度 |
| 隐秘 | 暗恋、把柄、共谋 | 只在对的时机显形，显形后威力最大 |

每条边三个属性：**类型 / 强度 1–5 / 可见性**（公开 / 圈内 / 只有当事人）。

### 9.2 边的数量与分布

- 核心 18 人：**36 条边**，平均每人 4 条。
- 枢纽（斯内普 6、邓布利多 7、哈莉 6）必须 ≥5。
- 深线守门人（妮可 / 阿利安娜 / 海伦娜 / 格林德沃）各 ≥3，且至少一条指向邓布利多。
- 浅节点 40 人：每人 **1 条**指向核心（玩家不可见，只用于正文里的称呼与站队）。

### 9.3 三种把网变成玩法的方式

**牵动**（写死在人设里，脚本执行）
```
A 升 Rank 6 → A×B 边强度 +1
A 升 Rank 9 → A×B 边状态改「结盟」或「破裂」（二选一，写死）
```

**前置**
```
A 的 Rank 7 需要 B 的 Rank ≥4
「她不信任任何没被 B 认可的人」
```
一句话就能逼玩家去经营另一个人。这是网最便宜也最有效的用法。

**行间联动**
带 A 进本、B 出现在偶遇池 → 解锁专属分支（只在两人边强度 ≥3 时）。

### 9.4 变量落点（纪律）

- **静态边**：写在世界书人设的【关系网】段，不占变量、不占常驻。
- **动态变化**：`/网/{A}▸{B}` = `{状态, 强度}`，**只存变过的边**，上限 40。
- 36 条静态边如果全存变量，会炸上下文；只存「变过的」就够。

### 9.5 浅节点怎么用

40 人只有一条边、一个态度、一句外形。他们不升级、不给奖励，只在三种场合出场：

1. 课堂与走廊的日常（让学校像个学校）
2. 学年线的群众场面（分院、宴会、比赛）
3. 涨潮的受害者（逾期时谁失踪、谁受伤，得有名有姓）

## 10. 一次完整的升 Rank（走一遍数）

```
周三 slot，玩家 <act do="陪人" target="罗娜·韦斯莱"/>
日程脚本：本周已用 1/4，时段 下午
模型写戏：罗娜因为成绩单的事躲在球场看台，主角陪她坐到天黑
结尾：<affinity name="罗娜·韦斯莱" kind="共患难" delta="+10" reason="陪她坐到天黑，没劝她"/>
社群脚本：
  ① 名单内 ✓
  ② 共患难 cap 10 ✓，本周第一次 ✓
  ③ 社群点 78 → 88
  ④ 新 Rank = 1+8 = 9；门槛：罗娜最看重 共情，需 5 阶，当前 3 阶 ✗
     → Rank 停在 8，回执「她愿意再走近一步，但你还差点什么」
  ⑤ 不升级，不发奖励
回执条：罗娜·韦斯莱 社群点 88/100｜Rank 8（差 共情 5 阶）
```

玩家看到回执就知道下一步该去刷共情，而不是继续陪她——**这就是「攻略谁等于成为什么样的人」**。
