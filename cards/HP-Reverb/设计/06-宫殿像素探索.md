# 06 · 宫殿 · 像素探索层

> **定位**：这是宫殿的**地图与操作层**——走、看、开、躲、撤。
> **战斗层**走 `10-战斗-八方旅人.md`（护盾 Break / BP 增幅 / 弱点发现 / 行动队列），本文件不重复定义战斗。
> **九座主宫殿**见 `07-九宫殿.md`，**22 张塔罗**见 `08-二十二塔罗.md`。
> 现实层（日程 / 社群 / 五维 / 涨潮）见 `00`–`04`。

---

## 1. 一句话

**白天的霍格沃茨是日程表，夜里的宫殿是一款能真的走进去的 8-bit 像素游戏。**

探索是「看见她怎么想事情」：走廊为什么这么长、门为什么锁着、镜子里的为什么是另一个她。
战斗是「跟她心里挡路的东西打」。打完之后回到现实——她变了，还是没变。

**肉鸽的位置**：地图每学年重组、掉落每局随机、失败损失真实；等级与装备跨局保留。是 roguelite，不是硬核肉鸽。

## 2. 三层架构

| 层 | 谁 | 负责 | 不负责 |
|---|---|---|---|
| 前端（iframe + canvas） | 眼睛与手 | 画地图、移动、碰撞、雾、遇敌、菜单、战斗界面 | 不写叙事、不判改心 |
| 脚本（酒馆助手） | 裁判 | 地图生成、资源、遇敌判定、战斗数值、存档、改心判定 | 不写正文 |
| 模型（LLM） | 嘴 | 每间房的描写、遭遇开场、Boss 三阶段、改心三拍 | 不写坐标、不写伤害数字 |

```
按键 → 前端移动 → 触发事件 → 前端写 /宫殿/事件
     → 脚本结算资源与遇敌 → 战斗走 JRPG 层
     → 模型读「摘要」写 2–4 段
     → 前端读新状态刷新
```

**纪律**：前端不掷骰；模型只拿摘要（`[宫殿] 马尔福庄园 2F · 遇敌 3 · HP−42 · 钥匙×1 · 警戒 36`）。

## 5. 地图生成（肉鸽层）

### 5.1 结构

每座主宫殿 **3–5 层**（大宫殿 5 层，小宫殿 2–3 层），每层 **24×18**，房间以「屏」为单位：
一屏 = 24×18，层与层之间用楼梯。

```
seed = hash(宫殿 id, 学年, 周)
① 迷宫骨架：随机挖通道 + 房间，保证起点到楼梯连通
② 房间类型：按权重放（走廊 / 厅堂 / 机关 / 宝库 / 安全屋 / 镜厅 / 守门）
③ 内容：宝箱 2–4、陷阱 1–2、敌人 2–5、机关 0–1、事件点 0–1
④ 主题化：按宫殿 tile 集与配色重绘
⑤ 校验：从入口到楼梯必须有一条 40 步以内的路（超了重挖）
```

**每学年重组一次**。同一座宫殿第二年进去，墙的位置不一样——「它会记事，也会改主意」。

### 5.2 房间类型

| 类型 | 特征 | 作用 |
|---|---|---|
| 走廊 | 窄，地形多 | 消耗灯火，暗雷 |
| 厅堂 | 空、大 | 明雷战斗 |
| 机关房 | 拉杆 + 门 | 解谜，错序重置 |
| 宝库 | 宝箱 3–4 | 资源 |
| 安全屋 | `R` | 存档 / 换人 / 半恢复 |
| 镜厅 | 镜子 3–5 | 真相碎片 + 剧情 |
| 守门室 | 单入口 | Boss 前哨 |
| 秘宝之间 | 单入口 + 光 | 核心层终点 |

## 6. 探索资源

| 资源 | 初始 / 变化 | 归零 |
|---|---|---|
| **灯火** | 每层 220；每步 −1；特殊地形 −2；安全屋 +80 | 全黑：遇敌率翻倍，踩空扣 5 HP |
| **钥匙** | 宝箱 / 敌人掉落 +1 | — |
| **意志** | 3，每过一层 +1，上限 9；撤离即清 | — |
| **警戒（回声）** | 被发现 +5；战斗失败 +10；警报 +20；躲藏 −2/回合 | **100 = 强制撤离** |
| HP / MP | 队伍值（见 JRPG 层） | 全灭 = 撤退 |

**灯火是「这一层还能走多远」，警戒是「这栋楼多想留你」。** 两个数一起逼你决定还走不走。

## 8. 遭遇：探索 → 战斗的接口

| 类型 | 规则 |
|---|---|
| 明雷 | 地图上的 `E`，视野 3 格，向玩家移动 1 格/回合；碰触进战斗 |
| 暗雷 | 步数阈值 10–18 后，每步 12% |
| 先制 | 从背后接触敌人 → 我方先手；被从背后接触 → 敌方先手 |
| 逃跑 | 战斗内「逃跑」，成功率 50% + SPD 差 ×5%；失败浪费一回合 |

战斗本身按 `10-战斗-八方旅人.md`：
回合指令、七属性、护盾 Break、BP 增幅、弱点发现、行动队列、状态异常。
**探索层只提供地形与先制，不改战斗公式。**

地形对战斗的影响（轻量，最多 3 条）：

| 地形 | 效果 |
|---|---|
| 火旁 | 火属性 +10% |
| 水中 | 火属性 −10%，雷属性 +10% |
| 冰面 | SPD +10%，先制判定 +10 |
| 黑暗（灯火 0） | 全队命中 −10%，敌方先制 |

## 9. 改心（Clear）

一座主宫殿要通过，三件事缺一不可：

1. **秘宝**：在秘宝之间拿到（宫殿主最在意的那件东西）
2. **真相碎片 ×3**：散在镜厅与事件点，每个是一段被篡改的记忆
3. **退路**：打开 2 个退路口，或击败守门人

三者齐 → 改心成功：

```
宫殿主 Rank 上限从 5 解到 10
获得核心残留（跨学年保留）
宫殿坍塌，不可再进（改为「回忆房间」，只能看）
宫殿主接下来三次见面，第一句话都不一样
```

**没准备好时**：可以反复进，地图重组，秘宝不出现——「她自己还没准备好」。

## 10. 失败与撤离

| 情况 | 结果 |
|---|---|
| 警戒 100 | 强制撤离：本局碎片全失；触发一次不可逆后果（断网边 / 某人受伤 / 期限提前一周） |
| 全灭 | 撤退：碎片全失，体力 −20，伤势 +20 |
| 主动撤离 | 带走已拿到的碎片（受层数限制） |
| 中途退出 | 进度保留，下次从安全屋继续 |

**不写「游戏结束」。** 输的永远是某样东西，不是存档。

## 12. 前端实现要点

| 项 | 做法 |
|---|---|
| 载体 | 酒馆助手「前端界面」无沙盒 iframe |
| 渲染 | canvas 画地图与精灵；DOM 画 HUD、菜单、对白 |
| 输入 | 方向键 / WASD / 虚拟十字键；A 交互；B 菜单 |
| 状态 | 读写 `/宫殿/*`；每 200ms 拉一次，避免与脚本打架 |
| 性能 | 只重绘变化的 tile；sprite sheet 单图 |
| 降级 | 无 canvas → ASCII + 指令；不想玩 → 「自动探索」按概率结算，只出摘要 |

**不做**：多层视差、粒子、过场动画、动态光照。这是 GB，不是 Unity。

## 15. 一局的时间感

| 阶段 | 现实时间 | 在做什么 |
|---|---:|---|
| 选宫殿、编队 | 1–2 分钟 | 带谁（被动决定能不能看见密门） |
| 第一层 | 5–8 分钟 | 摸清主题，第一次遭遇 |
| 中层 | 8–12 分钟 | 机关、镜子、真相碎片 |
| 核心层 | 5–8 分钟 | 守门战 + 秘宝 + 撤退 |
| 合计 | **20–30 分钟** | 消耗 2 行动点，可分 2 次潜入 |

一年 43 周，最多 43 个周末；玩家实际只会进 10–15 次。**宫殿不是日常，是节日。**
