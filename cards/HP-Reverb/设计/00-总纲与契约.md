# 00 · 总纲与契约

> 本目录是 HP-Reverb 的施工图。本文件定义全局刻度、模块依赖、请求契约、变量 schema 与预算。
> 其余 5 份文件各自展开一个模块，**所有数字以本文件为准**，模块文件只做细化，不改刻度。

---

## 1. 五条设计原则

1. **一个字段只有一个人写。** 模型只发请求，脚本决定结果；任何字段出现第二个写入方，就是 v10.1 那种「rank 三套规则」的起点。
2. **玩家做的每一个选择都要花掉某种不可再生的东西。** 行动点、时间、回声、人情、某人这一次的耐心。没有成本的选项不是选择。
3. **失败只推进麻烦，不判死。** 死了就没有下一次取舍；麻烦会把取舍推到更难的地方。
4. **规则只在常驻里写一次。** 同一件事写在两条常驻里，迟早对不上（v10.1 的 `<check>` 与 `<roll>` 就是这么烂的）。
5. **每一条内容都要能回答「它在哪个循环里被用到」。** 回答不了的，删。

## 2. 全局刻度总表

| 项 | 刻度 | 说明 |
|---|---|---|
| 时间单位 | **周** | 一学年 43 周（9/1–6/26） |
| 每周行动点 | **4**（周三 / 周五 / 周六 / 周日各 1） | 用完即进入下一周 |
| 一学年行动点 | **172** | 43 × 4 |
| 潜入消耗 | **2 点**（周六 + 周日整块），每周 ≤1 次 | 占满周末 |
| 上课 | 每周自动 1 次，不耗点 | 每 2 周给学业 +1 经验 |
| 五维 | **1–5 阶**，开局 **2**，每阶 **6 经验** | 每学年每维最多获得 12 经验（≤2 阶） |
| 社群 | **Rank 1–10**，点数 **0–100**，每 10 点一级 | 一次陪人 +8（短行动 +2，关键 +10） |
| 社群门槛 | R3 → 该维 ≥3；R6 → ≥4；R9 → ≥5；R10 → 任意三维 ≥4 且满点 | 「该维」＝她最看重的那一维 |
| 检定 | 1d100 低掷，难度 65 / 50 / 35 / 20 | +15 内部分成功；≤3 极值成功；≥98 极值失败 |
| 体力 / 魔力 / 伤势 | 0–100 | 体力＝HP，魔力＝SP，伤势跨局 |
| 回声 | 0–100 | 一次潜入的血条兼警戒 |
| 意志 | 开局 3，每过一重 +1 | 局内货币，撤离即清 |
| 行间 | 5 重 × 4–6 部位 × 6 门 × 4 深线 | 一次 run 约 5–8 楼 |
| 期限 | 每学年 **3** 次 | 第 9 / 17 / 43 周末 |
| 声望 | **−3 ~ +5 阶** | 连续值改阶，少一个算错的地方 |
| 秘密 · 发现度 | **0–100** | 哈莉线的主压力（见 `07`） |
| 常驻预算 | **≤12,000 字** | 条目总数 ≈194 |

**评分口径统一**：所有「够不够」都用阶或 Rank 判断，不再出现 0–100 的中间值给模型心算。

## 4. 契约层（全卡唯一请求语法）

### 4.1 五类请求

| 请求 | 语法 | 受理 |
|---|---|---|
| 行动 | `<act do="陪人" target="罗娜·韦斯莱" slot="下午"/>` | 日程脚本 |
| 检定 | `<roll type="咒语命中" dc="普通" attr="魔力" skill="魔药学" spell="除你武器" foe="精英" axis="胆识" target="X" action="撤退" retry="false"/>` | 对峙脚本 |
| 好感 | `<affinity name="罗娜·韦斯莱" kind="帮助" delta="+8" reason="替她挡了扣分"/>` | 社群脚本 |
| 事件 | `<event kind="主线节点" name="入学与分院" state="已完成" date="1991年09月01日"/>` | 剧情脚本 |
| 能力 | `<ability kind="咒语" name="荧光闪烁 0→2" cost="魔力 3">杖尖稳住了一点。</ability>` | 模型直写，脚本只校验范围 |

### 4.2 枚举（写死在契约里，别处不得复述）

```
act.do   : 陪人 | 自习 | 打工 | 采买 | 短行动 | 休息 | 潜入
slot     : 周三 | 周五 | 周六 | 周日          （不是「下午/夜晚」——时段由 slot 推定）
roll.type: 咒语命中 | 魔药成败 | 决斗 | 疑点调查 | 说服 | 潜行 |
           照料生灵 | 变形操作 | 炼金配比 | 飞行机动
roll.dc  : 简单 | 普通 | 困难 | 极难
roll.foe : 普通 | 精英 | 首领 | 灾厄
roll.action: 撤退 | 投降
affinity.kind: 对话 | 帮助 | 送礼 | 共患难 | 检定 | 任务
affinity.line: 未开始 | 进行中 | 已完成 | 失败
event.kind : 主线节点 | 支线 | 社群
event.state: 未触发 | 进行中 | 已完成 | 已改写
```

### 4.3 三条硬规矩

1. **`<check>` 只能由脚本产出。** 模型直接写 `<check>` → 正则剥离，回执里记一条 warn。
2. **没有请求就不推进数值。** 日常寒暄不掷骰、不加点、不写变量。
3. **解析不了的请求不许原样留在正文里。** 未知 `type` → 降级为 `咒语命中 / 普通` 并记 warn；未知 `do` → 当「休息」处理并记 warn。

### 4.4 示例（一次完整回合）

```
<act do="陪人" target="罗娜·韦斯莱" slot="周三"/>
```
→ 日程脚本扣 1 点，写 `/日程/本周已用 +1`
→ 模型写一场戏，结尾发 `<affinity name="罗娜·韦斯莱" kind="帮助" delta="+8" reason="……"/>`
→ 社群脚本算点、判 Rank、发奖励、弹回执
→ 模型最后输出 `<UpdateVariable>` 只补叙事性变量（如 `当前事件`），数值一律由脚本写

## 6. 路径白名单

所有 Patch 必须先过白名单：

```
允许的前缀（15 个）：
/主角 /世界线 /时空 /日程 /五维 /关系 /网 /潜伏 /行间 /能力
/物品与金钱 /守护神 /主角状态 /事件线索 /期限
```

不在白名单 → 丢弃 + warn + 回执条显示「已拦截 N 条非法路径」。
**这一条是防 v10.1「幽灵关系键」的唯一办法**：模型写 `/关系/德拉科娅·马尔福·rank 3` 会被拦，不会造出半个不存在的人。
