# 20 · 像素游戏定稿：美术 · 怪物 · 解密 · 小人制作

> 这份是**游戏本身的定稿**。工程方案见 `15`，玩法见 `06/07/10`，分发见 `16`。
> 精确到：**像素怎么画、怪物长什么样、解密怎么解、小人怎么造**。
> 原则：**不逆向任何商业游戏**——只提取公开可描述的通用设计语言（GB 时代的瓦片/调色板/限制），然后自己造 100%。

---

## 0. 先定死一个约束：什么能做、什么不做

| 项 | 定死 |
|---|---|
| 分辨率 | **320×180**，16px 瓦片，**20×11 瓦片视口** |
| 房间 | **24×18 瓦片**（384×288），比视口大一圈，轻微滚动 |
| 调色板 | **每座宫殿 16 色**（4 明度 × 4 相位），UI 单独 8 色 |
| 角色精灵 | **16×16**，4 向 × 3 帧；**8 套身体 × 22 组配色** |
| 敌人 | 杂兵 **32×32**，精英 **48×48**，Boss **64×64**（分块绘制） |
| 动画 | 走路 3 帧、攻击 2 帧、受击 1 帧、死亡 3 帧、Break 2 帧 |
| 字体 | **canvas 只画图，文字全走 DOM**（中文不点阵化） |
| 音频 | WebAudio 方波/三角波，12 音效 + 4 段 8 秒循环 |
| 外部素材 | **0 张图片、0 个音频文件**。全部是代码里的像素数组 |

**不做**：等距视角、多层视差、动态光照、粒子系统、骨骼动画、阴影渐变。这是 GB，不是 Unity。

## 1. 美术风格定稿

### 1.1 一句话风格

> **「1991 年的霍格沃茨被一台 Game Boy 记住了。」**
> 低饱和、高对比、四阶明度；阴影用抖动（dither），不用渐变；每个房间只有 3–4 个视觉焦点。

### 1.2 三条硬规则

1. **只用四阶明度**：每个色相只有 `暗 / 中 / 亮 / 高光` 四级。禁止第 5 级。
2. **阴影用抖动**：两阶之间用 50% 棋盘格过渡（`█▚` 交替），**不用平滑渐变**。
3. **轮廓线只用最暗的一阶**，1px；高光只用最亮的一阶，1px。不加第二层描边。

### 1.3 九座宫殿的调色板（各 16 色）

| # | 宫殿 | 主色相 | 氛围 | 特征色 |
|---:|---|---|---|---|
| 1 | 混血王子的地窖 | 黑绿 | 冷、湿、有药味 | `#4f6b4a` 药草绿 · `#c98b52` 铜 |
| 2 | 马尔福庄园的地基 | 冷白 + 银 | 太亮、太整齐 | `#e8eef2` 冷白 · `#8fa3b0` 银灰 |
| 3 | 五十年前的日记 | 暖褐 + 米 | 太干净、太暖 | `#d8c4a0` 米 · `#7a5a3a` 褐 |
| 4 | 第十二年的牢房 | 铁灰 + 锈 | 冷、铁锈味 | `#5a6068` 铁 · `#8a5a3a` 锈 |
| 5 | 满月的房间 | 蓝紫 + 月白 | 夜里、潮、发冷 | `#2a3a5a` 夜蓝 · `#c8d8f0` 月白 |
| 6 | 重复的走廊 | 青 + 金 | 旧、慢、回声 | `#3a5a5a` 青 · `#b89a4a` 旧金 |

### 1.4 瓦片清单（每座宫殿 32 块，共用模板）

| 组 | 数量 | 说明 |
|---|---:|---|
| 地面 | 4 | 空地、花纹地板、水/泥、裂纹 |
| 墙 | 8 | 上中下、转角 ×4、带门洞 ×2 |
| 门与锁 | 4 | 锁门（关/开）、密门、铁栅 |
| 楼梯 | 4 | 上下各 2 帧 |
| 装饰 | 8 | 书架、瓶架、镜子、画像、火炬、藤蔓、碎石、水渍 |
| 交互 | 4 | 宝箱（关/开）、拉杆、事件点 |

### 1.5 抖动的三种用法

```
50% 棋盘   ▚▚   两阶之间的过渡
25% 点阵   ▖    高光边缘
竖条纹     ▍    墙面的垂感
```

**规则**：同一屏内抖动总面积 ≤ 15%，否则会糊。

## 2. 像素小人怎么做（这是全篇最实操的一节）

### 2.1 尺寸与骨架

16×16，**头占 6px、身占 7px、脚 3px**（GB 时代的 Q 版比例，约 3 头身）。

```
行 0–5   头（含发、脸、可选的帽/眼镜）
行 6–12  躯干（衣领、袍子、手臂）
行 13–15 脚（裙摆/裤脚/鞋）
```

### 2.2 四向 × 三帧

| 朝向 | 帧 A | 帧 B | 帧 C |
|---|---|---|---|
| 下（正面） | 站立 | 左脚前 | 右脚前 |
| 上（背面） | 站立 | 左脚前 | 右脚前 |
| 左 | 侧身站立 | 迈左 | 迈右 |
| 右 | 左侧镜像 | 镜像 | 镜像 |

**右向直接水平镜像左向**，省一半工作量。

**帧 B/C 只改 3–4 个像素**（脚与肩），其余不动——这是 GB 时代的标准做法，也是最省力且最像的。

### 2.3 像素数组的写法

每一帧用一个 16 行字符串数组，数字是调色板索引：

```js
// 0=透明 1=最暗 2=中暗 3=中亮 4=亮 5=高光（6 色小调色板）
const HERO_DOWN_A = [
  '................',
  '.....111111.....',
  '....12222221....',
  '...1223333221...',
  '...1233443321...',   // 脸：3=肤色 4=高光
  '...1234443321...',
  '...1223333221...',
  '...1111111111...',   // 下巴阴影
  '..122233332221..',   // 领口
  '..122233332221..',
  '..122211112221..',   // 手臂
  '..122233332221..',
  '..122233332221..',
  '...1122222111...',   // 袍摆
  '...1221111221...',   // 脚
  '...111....111...',
];
```

**每个角色只换 6 色小调色板**：`1 暗` / `2 主色` / `3 皮肤` / `4 亮` / `5 高光` / `6 点缀`（如围巾、领带、袖扣）。

### 2.4 八套身体 × 22 组配色

| 身体 | 适用 | 差异点 |
|---|---|---|
| A 标准 | 大多数学生 | 中等肩宽，袍摆到膝 |
| B 高挑 | 教师、年长者 | 腿长 +1，袍摆更深 |
| C 娇小 | 一年级、家养小精灵 | 头大一点，腿短 1px |
| D 壮硕 | 海格、马人、混血巨人 | 肩宽 +2 |
| E 长发 | 长直发角色 | 后帧多 3px 发尾 |
| F 短发 | 短卷发 | 头顶加 2px 蓬松 |
| G 特殊 | 幽灵、妖精、狼人 | 半透明/耳朵/尾巴 |
| H 特殊二 | 哈莉（平行世界） | 校徽颜色错位 + 眼镜裂纹 |

**22 人分配**：把 `08` 的 22 张塔罗按体型分到这 8 套身体上，每人给一组 6 色彩。

### 2.5 制作流程（每人 3 步）

```
① 选身体（8 选 1）
② 选 6 色（调色板里点 6 个）
③ 加一个辨识点（眼镜 / 耳环 / 围巾 / 疤 / 发饰）
```

**第三点是关键**：像素小人靠一个「辨识点」认人。例：
- 哈利：圆眼镜（第 3–4 行两个亮点）
- 赫敏：蓬松头（头顶 +2px）
- 罗娜：暖色围巾（第 8 行一行 6 号色）
- 金妮：火红马尾（后帧多 4px）
- 阿利安娜（猫形态）：16×12 的小猫，不用人形
- 双子：**完全共用同一套精灵**，靠站位区分

**产出清单**：8 套身体 × 4 向 × 3 帧 = 96 帧；22 人只是换色 + 辨识点，**不额外画帧**。

### 2.6 动画帧率

| 动作 | 帧数 | 步进 |
|---|---:|---:|
| 走路 | 3 | 120 ms/帧 |
| 攻击 | 2 | 80 ms/帧，播一次 |
| 受击 | 1 | 100 ms + 闪烁 3 次 |
| 死亡 | 3 | 150 ms/帧，停在最后一帧 |
| Break | 2 | 交替闪 400 ms |

### 3.6 敌人的视觉语言

**三条规定**：
1. **一切敌人都是「被欲望扭曲的东西」**，不是怪兽：坩埚、信、画像、名字、纸、影子。
2. **每只敌人有一个"人的部分"**：一张脸、一只手、一个名字牌。
3. **弱点用颜色暗示**：火弱点带一点橙，光弱点带一点白边，暗弱点带一点紫。

## 4. 解密定稿

### 4.1 图例（八种机制，全部可复用）

| 记号 | 机制 | 规则 | 失败后果 |
|---|---|---|---|
| 🔑 | **门** | 需钥匙 / 钥匙卡 / 破门被动 | 无（找钥匙） |
| 🔘 | **拉杆** | 按顺序拉，错序重置房间 | 重置 + 灯火 −10 |
| 🪞 | **镜子** | 照出隐藏路径；**镜像里的操作与本体相反** | 回声 +5 |
| ⚖️ | **天平** | 用物品重量换开门 | 物块损毁 |
| 🕳 | **虚空** | 掉下去回到本层入口 | 灯火 −10 |
| 🧊 | **冰面** | 滑行 2 格，不可中途转向 | 撞墙停下 |
| 🔥 | **火** | 相邻扣 5 HP，可被冰熄灭 | 扣血 |
| 🚪 | **密门** | 只在带「识破/视野」被动时可见 | 无（可绕路） |

### 4.2 九座宫殿各一个专属谜题

| # | 宫殿 | 谜题 | 解法 | 提示在哪 |
|---:|---|---|---|---|
| 1 | 地窖 | **配药顺序** | 按"配方碎片"上的顺序取三味材料 | 碎片散在 3 个房间，集齐才看得懂 |
| 2 | 庄园地基 | **家徽顺序** | 龙—蛇—杖—冠，错序灌水 | 5F 门口的族徽浮雕 |
| 3 | 日记 | **契约盘** | 每接受一次好意，就要还一次；找到"不用还"的那一扇 | 镜子里没有她的房间 |
| 4 | 牢房 | **摄魂怪巡逻** | 灯火 <50 时它会主动追 | 墙上的划痕计数 |
| 5 | 满月 | **月相** | 每层月相推进一档，满月时狼形出现 | 窗外的月 |
| 6 | 走廊 | **回溯** | 同一机关第二次走答案不同；每层可回溯一次 | 楼梯上的刻痕 |
| 7 | 规章迷宫 | **违规** | 必须违反一条校规才能前进 | 每条校规旁的日期 |
| 8 | 那一天 | **循环** | 找出"正确的那一次下午"（家具位置 + 缺失的字） | 台词少一个字 |
| 9 | 墓园 | **七魂器** | 每破坏一个整张地图重写 | 祭坛上的七道裂口 |

### 4.3 谜题设计三原则

1. **提示必须在同一层**：不许让玩家去别处找。
2. **错误不惩罚进度**：重置代价是灯火/回声，不是重来整座宫殿。
3. **每个谜题要有一个"啊"的瞬间**：不是算术，是"原来镜子里的我是反的"。

## 5. 一屏的视觉重心（防止糊）

每个房间只允许 **3–4 个焦点**：

| 焦点类型 | 例子 | 用法 |
|---|---|---|
| 光源 | 火炬、窗、镜面 | 高光色，1–2 处 |
| 事件点 | 宝箱、镜子、事件 | 强调色，1–2 处 |
| 危险 | 火、虚空、敌人 | 最亮或最暗，1 处 |
| 出口 | 楼梯、门 | 视线引导 |

**背景永远比焦点暗两阶**。这是 GB 时代保证"一眼能看到该看的东西"的土办法。

## 9. 关于"逆向一个像素游戏"

**不做。** 三个理由：

1. **法律**：拆商业游戏的素材与代码属于侵权，而且会把整张卡的发布拖进风险。
2. **不必要**：GB/GBA 的瓦片、调色板、Q 版比例、3 帧走路，是公开的设计语言，描述得出来就不需要拆包。
3. **不划算**：逆向能给的其实只有"他用了 16 色"这一类信息，而那些我们已经定死了。

**真正该抄的是方法论**，不是资源：
- 3 帧走路只改脚和肩
- 四阶明度 + 抖动代替渐变
- 每屏 3–4 个焦点
- 右向镜像左向
- 敌人 = 被扭曲的日常物

这些足够做出 1991 年的霍格沃茨，而且每一像素都是自己的。

## 10. 一句话

**美术不是"画得好看"，是"一眼能认出谁、一眼能看出该往哪走"。**
在这套 320×180 的限制里，做到这两件事，就已经比大多数像素游戏强了。
