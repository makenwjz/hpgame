## 2. 逐件说明

### 2.1 PNG 打包器（`build-png.js`）

**已实现**：CRC32 表、`readChunks`、`makeChunk`、`textChunk`、删旧 `chara/ccv3`、插到 IEND 前、**回读校验**。

**要改的只有三行**：

```js
const SRC_PNG  = 'cards/HP-Reverb/art/cover.png';      // 新底图
const SRC_JSON = 'dist/card.json';                     // 我们的产物
const OUT_PNG  = 'dist/card.png';                      // 输出
```

**还要补一处**：它只写 `tEXt/chara`。我们的卡带 `ccv3` 需求时，加一个同样的 `textChunk('ccv3', payload)` 即可。

**结论**：W2 不是 1 天，是 **2 小时**。

### 2.3 状态栏渲染器（77 KB）

**里面已有的东西**（我白写了三天）：

| 能力 | 说明 |
|---|---|
| `CardwrightCore` 骨架 | 模块系统 + `renderBlock` 分派 |
| 六类 block | `stats` / `bars` / `tags` / `fold` / `text` / `roster` |
| **MVU 读取** | `waitMvu()` + `getMvuData({type:'message',message_id:'latest'})` + `getVariables` 兜底 |
| `resolve(data, path)` | 按 `/a/b/c` 取值，含 `{键}` 通配 |
| 状态栏 `statusHead` | summary 条 + pages 分页 + roster 折叠 |
| 主题令牌 | 五套主题（心之怪盗/镀金/羊皮纸/夜航/学院随色） |
| 安全 | `escape()`、`setAt` 防原型污染、`__proto__` 过滤 |

**复用方式**：**不重写，改 sheet**。

原卡的 sheet 是一段 `<script id="cw-sheet" type="application/json">`，里面写死了页与字段：

```json
{ "kind":"状态栏", "form":"header",
  "summary":[{"path":"/时空/日期","label":"日期","kind":"文本"}, ...],
  "pages":[{"name":"主角","blocks":[{"type":"stats","items":[...]}]}, ...] }
```

我们只要**换 sheet 的内容**，渲染器一行不用动：

- 六页改成：主角 / 五维 / 日程 / 关系 / 网 / 宫殿
- 字段路径换成我们的 15 容器
- `roster` 的 `gate` 从 `/关系/{键}/社群等级` 改成 `/关系/{键}/Rank`

**结论**：W1 不是 3 天，是 **1 天**（改 sheet + 调样式）。

### 2.4 创角页渲染器（75 KB）

同 2.3，也是「渲染器 + sheet」结构。原卡 sheet 有 7 步：

```
开局 → 姓名 → 性别 → 血统出身 → 志愿魔杖 → 性情倾向 → 旧识 → 增补
```

我们按设计只要 **3 栏**（五维倾向 / 魔杖 / 学院），所以：

- 删掉「开局」「姓名」「性别」三步（主角固定男哈利）
- 保留「血统出身」「志愿魔杖」
- 把「性情倾向」改成给五维 +2 经验
- 「旧识」保留（初始关系倾向）

**结论**：W1 的创角页 **半天**。
