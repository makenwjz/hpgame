# 07 · 序章、主角与哈莉线

> 本文件定死三件事：**主角是谁**（男版哈利，固定）、**开局只剩三个选项**、**哈莉怎么出场**（第 1 周末夜，同一张床）。
> 它同时引入一个新系统：**秘密 / 发现度**。这是第一条弧的主压力。

---

## 1. 主角固定：哈利·波特

| 项 | 值 | 是否可选 |
|---|---|---|
| 姓名 | 哈利·波特 | 固定 |
| 性别 | 男 | 固定 |
| 年龄 | 18（1991 年入学，七年级制的高等部一年级） | 固定 |
| 血统 | 混血（母亲莉莉是麻瓜出身，母亲詹玛是纯血） | 固定 |
| 出身 | 萨里郡女贞路，德思礼家养大；达莉护着他 | 固定 |
| 学院 | —— | **可选** |
| 魔杖 | —— | **可选** |
| 五维 | 开局各 2 阶 | **可微调** |

**世界设定**：这是一处全员娘化的巫师界，登场角色一律女性。**哈利是全校唯一的男性学生**——这件事本身就是设定，不是补丁。

它带来三个直接后果：

1. **男生宿舍是单独一间**（塔楼顶层改造，无室友）——所以哈莉有地方藏。
2. **纯血家族把他当血脉筹码**：唯一的男丁，联姻价值极高，态度会比对女版更露骨。
3. **同性同学没有「兄弟」这层缓冲**：所有关系都从「一个男生和一群女生」开始，距离感天然更紧。

## 2. 创角页：只剩三栏

v10.1 是七步；这是三步。

### 第一栏 · 五维倾向

开局五维各 **2 阶**，另给 **3 点倾向**：每点让指定一维 +2 经验（满 6 升阶）。

- 全点一维 → 该维 3 阶（其余 2 阶）
- 分散点 → 两维各 +3 经验，都不升阶
- 这是**唯一一次**可以越过「每学年每维 ≤2 阶」的机会，所以值得犹豫

### 第二栏 · 魔杖

木材 + 杖芯各选一，不掷骰。

| 木材 | 起始专精（学得比常人快） |
|---|---|
| 冬青木 | 守护神系 / 除你武器 |
| 紫杉木 | 咒咒 / 黑魔法防御 |
| 柳木 | 治疗 / 治愈类 |
| 山楂木 | 决斗类 |
| 葡萄藤木 | 变形 |
| 榉木 | 魔咒（通用） |

| 杖芯 | 起始加成 |
|---|---|
| 凤凰羽毛 | 守护神觉醒提前一学年 |
| 独角兽毛 | 治疗类检定 +2 熟练 |
| 龙心弦 | 攻击类咒语 +2 熟练 |
| 媚娃头发 | 说服类 +1 判定（社交向） |
| 夜骐尾毛 | 行间里能看见「不该看见的」：偶遇池多一条 |
| 雷鸟尾羽 | 每局第一次对峙 +5 |

**哈莉的反应**：她认得那根魔杖的「另一种版本」。同木材会让她第一眼多看你两秒。

### 第三栏 · 学院

四选一。它决定：课表、公共休息室、级长、教授初始态度、以及**第一批网边**。

| 学院 | 起始关系 | 代价 |
|---|---|---|
| 格兰芬多 | 罗娜 Rank 1 起步（+5 点）、娜薇好感 | 德拉科娅对立 +1 |
| 斯莱特林 | 德拉科娅 Rank 1 起步（+5 点）、斯内普态度软化 | 罗娜/赫敏起步更慢 |
| 拉文克劳 | 赫敏/卢娜更早接触 | 魁地奇线关闭一学年 |
| 赫奇帕奇 | 塞德丽卡/汉娜/苏珊 | 主线情报晚一周 |

**分院仍由帽子定**，但因为只有一个男生，帽子会多问一句——这一句写死在开场，不许跳过。

## 3. 宿舍：塔楼顶层，只有一间

- 位置：格兰芬多塔楼再往上，一间改出来的单人房（原本是废弃的观测室）。
- 好处：独立、有窗、没人查夜。
- 坏处：**画像**。走廊上的画会说话，会告密，会记仇。
- 门锁是校规配的，不是魔法锁——所以一个会开锁的人能进来。

**这是整个序章的舞台。** 哈莉要藏的地方不是「某个房间」，是「学校唯一没有第二个人住的地方」。

## 4. 第 1 周：四天，四个决定

第 1 周是**序章周**，规则收窄：

| 项 | 第 1 周 |
|---|---|
| 行动点 | 4（周三 / 周五 / 周六 / 周日） |
| 上课 | 自动，给一次课堂戏 |
| 行间 | **不开放**（第 2 周才开） |
| 涨潮 | 无 |
| 短行动 | 每周 1 次 |

四个点用来：认识 2–3 个人、摸清宿舍、第一次被画像看见、以及**在周日夜里被弄醒**。

### 4.1 第一楼（first_mes）写到哪

站台 → 穿墙 → 车厢（罗娜）→ 渡湖 → 分院（帽子多问一句）→ 开学宴（邓布利多的短话、斯内普往这边看了一眼）→ 塔楼单人房第一夜。

**止于睡下，不写哈莉。** 哈莉是第 1 周末的事件，不是开场白。

## 5. 第 1 周末夜：同一张床

### 5.1 触发（脚本强制）

第 1 周第 4 个行动点用掉、周结算之前：

```
剧情脚本 → 检测 /时空/周 == 1 且 /秘密/哈莉已登场 == false
        → 强制插入事件「第 1 周末·同床」
        → 不听玩家的「我想先睡」
```

### 5.2 场景定式

> 帷幔里有动静。
> 不是风——塔楼顶层的窗关着。你伸手去够魔杖，指尖先碰到一段湿冷的布料。
> 然后是一只手，抓住你的手腕，力气大得不像刚醒的人。
>
> 她跟你差不多高，黑头发乱得像被谁揪过，眼镜歪在一边，镜片上有一道没擦干净的裂纹。
> 她的袍子是霍格沃茨的袍子，但袖口的校徽颜色不对。
> 她看了你很久，才说了一句：
>
> 「……你也是哈利·波特？」
>
> 她的手腕上有灰。不是烟灰，是行间那种墙灰。

**四个选项**（写在事件里，玩家必须选一个）：

| 选择 | 发现度 | 哈莉 | 后续 |
|---|---:|---:|---|
| 藏起来，先听她说完 | +5 | +10 | 第 2 周开始「藏匿」玩法 |
| 立刻去找麦格 | 0 | −15 | 邓布利多线开启，哈莉被带走观察三天后放回（发现度已 0，但学校知道了） |
| 直接送校医院 | +20 | +5 | 庞弗雷封口，但画像看见了 |
| 把她的手甩开 | +10 | −30 | 她当夜消失，第 3 周才在行间里重逢 |

**四种选择都必须能玩下去**，不许有「选错即死」。差别在于：前两周的节奏、谁先知道、以及哈莉对你的初始态度。

### 5.3 为什么是「一张床」

不是巧合，是设计：

- 行间的裂缝只开在**「一个人真正觉得是自己的地方」**——他的床。
- 这也解释了为什么她掉在他身上，而不是走廊上。
- 它同时完成了三件事：**关系起点、秘密起点、以及「你有一个不能让画像看见的东西」**。

## 6. 秘密 / 发现度（新系统）

### 6.1 变量

```yaml
秘密:
  发现度: 0              # 0-100
  哈莉已登场: false
  哈莉所在: ""           # 宿舍|行间|失踪|被带走
  共谋者: []             # 知道哈莉存在且愿意保密的人，≤5
```

### 6.2 涨落

| 事件 | 发现度 |
|---|---:|
| 带她出宿舍（夜间） | +5 |
| 被画像看见 | +10 |
| 被级长/教授撞见 | +20 |
| 让她在白天待在宿舍（不外出） | 0 |
| 每周低调（不带出、不惹事） | −3 |
| 拉一个人做「共谋」（需要 Rank ≥5 且边为「隐秘」） | −10（一次性） |
| 让她替你在课上出手 | +15 |

### 6.3 阈值

| 发现度 | 状态 |
|---:|---|
| 0–29 | 只有画像在嘀咕 |
| 30–49 | 级长开始问「你房间是不是有别人」 |
| 50–69 | 教授介入：麦格找谈话，宿舍被查一次 |
| 70–89 | 魔法部派人：邓布利多压下来，但限期两周 |
| 90–99 | 学校给出选择：交人，或开除 |
| 100 | 哈莉被带走（进「被带走」状态，只能通过行间救回） |

### 6.4 与社群的关系

发现度不是惩罚条，是**关系的另一种计价**：

- 愿意做共谋的人，`/网/{你}▸{她}` 会新增一条「隐秘」边，强度 1。
- 共谋者 Rank 6 的戏眼会自动变成「替你瞒住一件事」。
- 被发现得太多次，共谋者会掉点——她们不是工具。

## 7. 哈莉·波特（平行世界）

### 7.1 基础设定

18 岁，女性，另一个世界的「活下来的女孩」。
那个世界 1981 年那一夜是一样的：两位母亲死了，她活着。区别在于——她没有人替她挡镜头，从十一岁起就被当成符号养大，学会了用沉默对付所有问题。
她那个世界的行间塌了。她是被推出来的，不是自己走进来的。

**外貌**：黑色乱发、绿眼睛、细框圆眼镜（镜片有裂纹）、额角闪电形旧疤、比同龄人矮半个头、瘦。来时穿的是那个世界的格兰芬多袍子，袖口校徽颜色不对。

**性格三层**
- 表层：硬、话少、不求助。问一句答一句。
- 内在：她信「没人会替你挡」，所以永远先站到别人前面。
- 崩坏点：**被人当成「那个符号」而不是「一个人」**——她可以对任何危险保持冷静，唯独受不了被同情。

**说话**：句子短，不铺垫。不熟时几乎不开口；熟了会讲冷玩笑，也敢顶嘴。
**绝对不会做**：在别人面前哭；说「我需要帮忙」。

### 7.2 社群：一条特殊的线

| 项 | 值 |
|---|---|
| 最看重的一维 | **共情**（她想被当成普通女孩，而不是被崇拜或被同情） |
| 门槛 | Rank 3/6/9 → 共情 3/4/5 阶 |
| Rank 10 | 任意三维 ≥4 + 100 点 |
| 特殊 | 她的 Rank 7 会额外考一次**胆识**（她试你会不会退） |

**十级台阶（骨架）**

| Rank | 戏眼 |
|---:|---|
| 1 | 同床：她抓着你的手腕，问「你也是哈利·波特？」 |
| 2 | 藏匿：她学会在你房间里不出声，你学会替她圆谎 |
| 3 | 第一个白天：她第一次从窗帘缝里看霍格沃茨 |
| 4 | 她的伤：手腕上的灰洗不掉，她说那不是伤，是「被记住」 |
| 5 | 她讲那个世界：有两个母亲、有一场没打完的仗、有一个她没救下的人 |
| 6 | 她替你出手：在走廊上，她做了那个世界做过一百次的动作 |
| 7 | 她想回去：行间里有回去的门，她开始夜里站在窗前 |
| 8 | 门开了：第三重的裂缝，她站在门口等你选 |
| 9 | 选择：留下 / 送她回去 / 跟她走（三者只能选一个） |
| 10 | 结局：她的收尾，取决于第 9 级的选择 |

### 7.3 行间支援（她是可部署的「同伴」单位）

| 项 | 值 |
|---|---|
| 费用 | 8 意志（或直降，Rank 5 起免费一格） |
| HP | 40 |
| 攻 | 10/tick，阻挡 1 |
| Lv1（Rank 5） | **缴械**：每波一次，让一个敌人退 2 格 |
| Lv2（Rank 8） | 缴械变为 3 格，并造成 20 伤害 |
| Lv3（Rank 10） | 「她挡在你前面」：门受到致命漏怪时，她替你吃一次（本局一次） |

### 7.4 三个结局方向

| 选择 | 结局 | 深线 |
|---|---|---|
| 留下她 | 两个人一起留在这个世界，代价是这个世界的裂缝越来越大 | 生 |
| 送她回去 | 你把她推回门里，门关上，走廊安静了 | 空 |
| 跟她走 | 你跨过去，霍格沃茨留在身后 | 时 |

**没有一个是「正确」的。** 这正是整张卡的主题：取舍的重量。

## 8. 第一条弧（第 1–9 周）

| 周 | 内容 | 系统 |
|---|---|---|
| 1 | 开学、分院、四个行动点、**同床** | 序章 |
| 2 | 藏匿、行间开放、第一次潜入选择门 | 秘密 + 塔防 |
| 3 | 她第一次出宿舍（夜里）；画像开始嘀咕 | 发现度 30 |
| 4 | 她讲那个世界的开头；罗娜察觉你房里有人 | 社群 + 网 |
| 5 | 第一次三人同场：罗娜 / 德拉科娅 / 哈莉 | 三角冲突 |
| 6 | 她的手在课堂上被看见（或她忍住了） | 发现度 50 |
| 7 | 麦格谈话；邓布利多的试探 | 发现度 70 |
| 8 | 行间第三重出现「回去的门」；她开始夜里站着 | 塔防 + 深线 |

**第 9 周的三种走法**
1. **让她出手**：巨怪那一夜她替你挡下，发现度 +30，但她 Rank 直接 +2。
2. **不让她出手**：你的身体扛下，体力见底，她 Rank −1，但发现度不涨。
3. **把她推进门**：她回去了，第 02 学年她以「另一个世界的来信」形式继续存在（社群线转为信件）。

## 9. 写作口径（序章专属）

### 9.1 第一夜

**不写性。** 写「两个人在一张床上都不敢动」：

- 她背对着你，肩膀绷着，呼吸很浅。
- 你也不敢动，因为一动她就会跳起来。
- 天快亮时她睡着了，手还抓着你袖口。
- 第二天早上你们谁都没提这件事。

这一段的分寸是整条线的基调：**亲密不是从身体开始的，是从「谁先敢闭眼」开始的。**

### 9.2 男性主角的处理

- 不要写成「后宫开局」。全校只有一个男生这件事会带来**紧张**，不是便利。
- 纯血家族的态度露骨但不低级：联姻、试探、施压，不是投怀送抱。
- 女生们的反应分三类：好奇 / 戒备 / 无视。**无视的那一类最难攻略，也最值钱。**

### 9.3 NSFW

- 序章与第一条弧默认 SFW。
- Rank 6 起可触发；哈莉线第一次在 Rank 7 之后（她需要先相信你不会把她当符号）。
- 口径沿用 `04` 的《尺度与边界》。
