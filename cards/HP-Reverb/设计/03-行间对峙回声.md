> ⚠️ **夜间玩法已整体替换**：行间 / 部位 / 门的结构作废，改由 `06-宫殿像素探索.md` 的「宫殿」承接，九座宫殿见 `07-九宫殿.md`，可操作角色见 `08-二十二塔罗.md`。

## 1. 行间是什么

霍格沃茨的墙会动，房间会消失，有求必应屋能长出任何空间。**墙壁之间不在地图上的那些空腔**，就是行间。

它按闯入者的记忆重组——所以每次进去路都不一样。这一句同时解释三件事：

1. 为什么每次不同（肉鸽需要）
2. 为什么威胁日常（期限的来源）
3. 为什么值得反复进（残留与人）

**它不是一个需要征服的塔，是一个需要放弃的地方。** 每多走一个部位，回声就高一格；什么时候撤，才是这个系统的核心选择。

## 2. 一次潜入的流程

```
选门（决定开局增益与起始残留）
   ↓
第 1 重：生成 4–6 个部位，玩家选一条路
   ↓
逐个结算部位 → 全部走完或主动撤离 → 第 2 重
   ↓
每重结束：领一次「领会」（残留 / 加隆 / 意志 三选一）
   ↓
第 5 重：Boss 部位（守门人 或 核心残留守卫）
   ↓
撤离 或 被打出（回声 100）
   ↓
结算：残留带出（受深度限制）、加隆、社群牵连、回声清零、深线 +1
```

**楼数**：一次 run 约 5–8 楼（每重 1–2 楼）。占 2 行动点。

## 3. 六道门

门决定「这一局从一开始是什么形状」。门本身也是叙事：你在哪儿找到的入口，说明你当时在想什么。

| 门 | 位置 | 开局增益 | 代价 |
|---|---|---|---|
| 大厅门 | 大礼堂侧廊 | 开局带 1 件普通残留 | 无 |
| 厨房门 | 赫奇帕奇走廊 | 每重结束体力 +10 | 无 |
| 钟楼门 | 钟楼 | 开局回声 −10 | 无 |
| 湖底门 | 黑湖栈桥 | 开局意志 +2 | 天气要求：夜晚、无月 |
| 画像门 | 八楼画像后 | 第一个部位必为「余兴」 | 无 |
| 有求必应屋门 | 八楼 | 自选第一个部位类型 | 回声 +5 |

## 4. 八种部位

| 部位 | 结算 | 说明 |
|---|---|---|
| **对峙** | 1 次 `<roll>` | 有敌人，有弱点 |
| **急所** | 1 次 `<roll>`，难度 +1 档 | 奖励翻倍，**可以先拒绝**（拒绝不涨回声） |
| **偶遇** | 无骰 | 事件；选项受同行与网边解锁 |
| **静处** | 无骰 | 三选一：体力+15 / 魔力+15 / 意志+1 |
| **行商** | 无骰 | 用加隆或意志买残留 / 消耗品 |
| **岔路** | 无骰 | 捷径（少一个部位，回声 +15）或绕路（多一个部位） |
| **余兴** | 无骰 | 纯角色戏，同行者社群点 +5，回声 −3 |
| **涨潮点** | Boss | 第 5 重专属 |

**部位生成规则**：每重随机 4–6 个，其中至少 1 个「静处」或「行商」，最多 2 个「对峙」，Boss 不随机。

## 5. 意志

局内货币，撤离即清。

- 开局 **3**，每通过一重 **+1**，上限 9。
- 用途：

| 用途 | 花费 |
|---|---:|
| 招募一名同行（在行间里遇到的人） | 1 |
| 跳过当前部位（不结算、不涨回声） | 2 |
| 强化一件残留（本局该残留效果 +3） | 1 |
| 被打出时保底（残留不折半） | 2 |

**意志不能带出**。花不完就是浪费——这是设计，不是 bug。

---

## 6. 残留

行间里捡到的他人遗物，每件一个被动。

| 类型 | 效果 | 示例 |
|---|---|---|
| 判定类 | 特定类型对峙 +2~8 | 一枚旧级长徽章：说服类 +5 |
| 改写类 | 把下一个部位改成指定类型 | 半张地图：下一个部位变「静处」 |
| 重掷类 | 一次重掷（用掉即碎） | 断裂的怀表：重掷一次 |
| 减压类 | 回声 −5 | 一枚冷掉的纪念币 |

**规则**
- 每局最多带 7 件；**带出数量 ≤ 到达的重数**（第 3 重撤＝最多 3 件）。
- 重复的同类残留不叠加，取最高。
- 跨局保留的只有「核心残留」（4 条深线各 1 件），其余当季清空。

## 7. 敌人

| 敌人 | 强度 | 弱点 | 免疫 |
|---|---|---|---|
| 摄魂怪余响 | 精英 | 守护神系（呼神护卫） | 一切非护身咒语 |
| 蛇类造物 | 普通 | 蛇佬腔 / 火焰 | 精神类 |
| 博格特 | 普通 | 笑声 / 变形术 | 直接攻击 |
| 亡灵与残忆 | 精英 | 火焰 / 净化 | 物理 |
| 巨人造物 | 首领 | 缴械 / 石化 | 小型咒语 |
| 痴愚之核 | 灾厄 | 智识（博识 / 解谜） | 暴力 |

**弱点命中**：判定线 +10，并触发一次**追击**。
**弱点错配**：判定线 −10。
**全弱点命中**（同场把 2–3 个弱点都打中）：触发**合围**，战斗直接结束，额外给 1 件残留。

## 8. 对峙（全卡唯一的掷骰）

### 8.1 判定线

```
判定线 = 50
  + 学派修正：对应课程所属学业阶 × 2            （上限 +10）
  + 咒语熟练：floor(熟练度 ÷ 2)                 （0–20 → 0~+10）
  + 同行支援：3 × 同行人数 + 支援加成            （支援 Lv1/2/3 = +2/+3/+5，上限 +5）
  + 残留修正：每件 2~8，合计上限 +12
  + 五维修正：(阶 − 2) × 2，上限 ±6
  − 敌人强度：普通 0 / 精英 5 / 首领 10 / 灾厄 15
  − 回声惩罚：≥60 → −5；≥80 → −10（取一项）
  − 伤势惩罚：伤势 ≥50 → −5
夹 5–95
```

> 例：学业 3 阶（+6）+ 熟练 12（+6）+ 同行 2 人（+6+3）+ 残留 +4 + 胆识 4 阶（+4）
> − 精英 5 − 回声 62（−5）= **69**。

### 8.2 判定

| 骰面 | 结果 |
|---|---|
| ≤3 | **极值成功**：成功，且不记伤势，回声只 +1 |
| ≤ 判定线 | 成功 |
| ≤ 判定线 + 15 | 部分成功 |
| 其余 | 失败 |
| ≥98 | **极值失败**：失败，且惩罚 ×1.5，回声额外 +5 |

### 8.3 结算表（十类）

| 类型 | 主属性 | 成功 | 部分成功 | 失败 |
|---|---|---|---|---|
| 咒语命中 | 魔力 | 魔力 −3 | 魔力 −6，伤势 +3 | 魔力 −10，伤势 +5 |
| 魔药成败 | 魔力 | 魔力 −2 | 魔力 −4，伤势 +3 | 体力 −8，伤势 +5 |
| 决斗 | 体力 | 体力 −5 | 体力 −10，伤势 +5 | 体力 −15，伤势 +10 |
| 疑点调查 | 魔力 | 体力 −2 | 体力 −5 | 体力 −5，伤势 +5 |
| 说服 | 声望 | 无 | 目标社群 −2 | 目标社群 −5（极值失败另 −1 声望阶） |
| 潜行 | 体力 | 体力 −3 | 体力 −5，伤势 +2 | 体力 −8，伤势 +5 |
| 照料生灵 | 魔力 | 魔力 −2 | 魔力 −4 | 魔力 −6，伤势 +3 |
| 变形操作 | 魔力 | 魔力 −3 | 魔力 −6，伤势 +3 | 魔力 −10，伤势 +6 |
| 炼金配比 | 魔力 | 魔力 −2 | 魔力 −4，伤势 +2 | 魔力 −8，伤势 +6 |
| 飞行机动 | 体力 | 体力 −4 | 体力 −8，伤势 +4 | 体力 −12，伤势 +8 |

**乘难度系数**（简单 0.6 / 普通 1 / 困难 1.4 / 极难 1.8），取整，非零至少 1。
**单次上限**：体力 40、魔力 40、伤势 30、社群 10。

### 8.4 三个特别动作

| 动作 | 规则 |
|---|---|
| 撤退 | 用 `<roll type="决斗" action="撤退">`；成功干净退开，失败被截住 |
| 投降 | **不掷骰**，只看对手收不收手（按敌人类型与剧情判） |
| 重试 | `retry="true"` 时难度自动升一档，堵住刷结果 |

### 8.5 修正来源的硬规矩

- 属性只看 `魔力 / 体力 / 声望`（各以 50、50、0 为中线）。
- 熟练度只在指名 `spell` 时计算；不指名就不算。
- 五维修正取 `(阶−2)×2`：2 阶 = 0，5 阶 = +6，1 阶 = −2。
- **所有修正的来源必须在 `<check>` 里列出来**（`1d100=42，判定线 69（学业+6 熟练+6 同行+9 残留+4 胆识+4 精英−5 回声−5）`）。

## 9. 回声

### 9.1 涨

| 事件 | 回声 |
|---|---:|
| 成功 | +3 |
| 部分成功 | +8 |
| 失败 | +15 |
| 极值成功 | +1 |
| 极值失败 | 额外 +5 |
| 主动开大招：守护神全开 | +10 |
| 主动开大招：时间魔法 | +15 |
| 硬闯（不走岔路直接冲） | +8 |
| 余兴部位 | −3 |
| 钟楼门 | 开局 −10 |

### 9.2 三档状态

| 回声 | 叙事 | 机械 |
|---|---|---|
| 0–39 | 行间还是安静的 | 无 |
| 40–59 | 有什么在跟着你 | 偶遇池加一个「被注视」 |
| 60–79 | **行间认得你了** | 判定 −5；行商价格 +20% |
| 80–99 | 它在等你走错 | 判定 −10；敌人强度 +1 档；偶遇变凶 |
| 100 | 被打出 | 强制撤离，见 §9.3 |

### 9.3 被打出

```
① 立即结束本局
② 残留带出 = floor(已得件数 ÷ 2)
③ 触发一次不可逆后果（三选一，由本局最深的一条深线决定）：
   · 断一条网边（状态改「破裂」）
   · 一名同行者受伤（伤势 +30，社群点 −10）
   · 期限提前一周
④ 回声清零，体力 −25
```

**这条是整个重构里最重要的改动**：v10.1 的「代价」是主角的永久减益（体质/魔力上限/寿命/记忆），砍掉之后代价没有消失，而是变成了**这一局的紧张 + 局外的连锁**。

## 10. 深线

四条，不是开局选的，是走出来的。

| 深线 | 主题 | 守门人 | 核心残留 | 结局方向 |
|---|---|---|---|---|
| 生 | 疗愈与再生，代价是拿走别的生命 | 妮可·勒梅 | 炼金的初火 | 想留下所有人 |
| 死 | 与死者对话，代价是承认他们真的死了 | 阿利安娜·邓布利多 | 亡者之耳 | 想把死人带回来 |
| 时 | 重来的机会，代价是每次重来都少一点 | 海伦娜·拉文克劳 | 回响 | 想改掉某个下午 |
| 空 | 抵达任何地方，代价是永远回不到原处 | 格林德沃 | 隐匿 | 想离开这里 |

**深线值怎么涨**
- 每局结束：带出的残留里，与某条深线主题相符的 +1。
- 走某个守门人的门 / 在该深线的部位里完成偶遇：+1。
- 拿到核心残留：该深线 +3。

结局按最高深线值走；两条并列时按「最重的那次选择」判。

## 11. 第五重 Boss

| 类型 | 形态 | 破法 |
|---|---|---|
| 守门人 | 深线守门人本人 | 3 次成功 或 1 次合围；不打也能过（她用别的方式考你） |
| 核心残留守卫 | 由记忆拼成的怪物 | 2 个弱点，打中一个 +10，全中触发合围直接结束 |

Boss 战**不许**写成一回合定生死：至少三拍——试探、吃亏、找到破法。

## 12. 一次完整的 run（走一遍数）

```
周六，玩家 <act do="潜入" slot="周六" door="钟楼门"/>
日程脚本：本周已用 2/4，时段 夜晚，体力 −10
行间脚本：回声 0→0（钟楼门 −10 但下限 0），意志 3，重 1

第 1 重 · 4 个部位：对峙(蛇类造物) / 静处 / 偶遇 / 岔路
  ① 对峙：<roll type="咒语命中" spell="火焰熊熊" dc="普通" foe="普通" 弱点命中/>
     判定线 50 + 学业3阶(+6) + 熟练8(+4) + 同行2人(+9) + 残留0 + 胆识4阶(+4) + 弱点(+10) = 83
     掷 41 → 成功；魔力 −3；回声 0→3
  ② 静处：选「意志 +1」→ 意志 4
  ③ 偶遇：遇到卢娜（同行），花 1 意志招募 → 意志 3，同行 3 人
  ④ 岔路：选绕路（多一个部位）→ 回声 3→5

  第 1 重结束，领会三选一：拿残留「旧级长徽章（说服 +5）」
  重 1→2，意志 3→4（每重 +1）

第 2 重 · 5 个部位：偶遇 / 对峙(摄魂怪余响) / 行商 / 急所 / 涨潮点
  ……（略）
  第 3 重门口，回声 78，判定开始 −5，玩家决定撤离
  收盘：残留 3 件（到第 2 重，最多带出 2 件）
  加隆 +35，深线「死」+1
  体力 100→62，魔力 100→41，回声清零
```

**这一局的账**：2 行动点，换 2 件残留、35 加隆、一次深线推进、62 体力。玩家下一步要决定的是——这周还剩 2 点，是去陪人，还是休息。

## 13. 与日程的接口

| 时机 | 谁写 | 写什么 |
|---|---|---|
| 进入 | 日程脚本 | `/日程/本周已用 +2`，`/潜伏/在行间 = true` |
| 结算部位 | 行间脚本 | `/潜伏/{重,部位,回声,意志,残留,同行}` |
| 对峙 | 对峙脚本 | `/主角/{体力,魔力,伤势}` + 输出 `<check>` |
| 撤离 | 行间脚本 | 清 `/潜伏/*`，写 `/行间/记录`，`/主角/体力 −10` |
| 被打出 | 行间脚本 | 同上 + 不可逆后果 + 断边 |

**行间脚本不写 `/关系/Rank`、不写 `/五维`、不写 `/期限`**——它只能「申请」，由对应脚本执行。

## 14. 守护神（面具位）

Persona 有面具，本卡用守护神承接，但**不做合成**。

| 项 | 规则 |
|---|---|
| 觉醒 | 第 03 学年（或其他学年里第一次成功施放呼神护卫） |
| 形态 | 由第一次成功时的**主导深线**决定：生＝牡鹿／死＝犬／时＝鹰／空＝蛇 |
| 解锁条件 | 心志 ≥3 阶，且在行间里经历过一次「差点被打出」 |
| 作用 | 对摄魂怪余响视为弱点；每局一次「全开」：判定 +10，回声 +10 |
| 深线联动 | 核心残留拿到后，形态可再进化一次（改名 + 一次演出），不做数值叠加 |

守护神的形态一旦定下不改——这是全卡少数几个**不可逆的身份选择**之一。
