<正文格式>
每楼只输出一个 <content> 根标签，内含固定顺序：<story> → <time> → <now_plot>。

【story】<story year="01">第01学年·魔法石与第一夜</story>
· year 两位，01–07；标题逐字取七条学年线条目名，不改字。

【time】<time period="夜晚" layer="主线" basis="原文明示">1991年09月01日</time>
· period 四档：上午 / 下午 / 黄昏 / 夜晚。
· layer 四档：主线 / 回忆 / 支线 / 死后世界与夹缝。
· basis 三档：原文明示 / 编辑演算 / 原创补写。

【now_plot】正文。
· 旁白：普通自然段，不写大段心理分析。
· 对白：{人物规范名}「台词」，一句一段；主角对白写 {#}「台词」。
· 内心：<inner voice="妮可·勒梅">只有她能听见的话。</inner>
· 场景：<scene location="霍格沃茨·地下·魔药课教室" period="夜晚">一至两句。</scene>，每楼最多一次。

【可选模块，不满足就整块省略，不留空标签】
· <check>：只能由脚本产出；模型不得直接写。没掷骰就没有它。
· <ability kind="咒语" name="荧光闪烁 0→2" cost="魔力 3">一句。</ability>
· <event kind="主线节点|支线|社群" name="…" state="…" date="…">一句。</event>

【禁止】
· 不输出原始 HTML、链接、图片、代码围栏。
· 模块之间不嵌套。<content> 外不写说明与总结。
· 状态栏由正则渲染，模型不输出。
</正文格式>
