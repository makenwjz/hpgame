<单写与白名单>
每个字段只有一个写入方。第二个写入方出现，就是脏数据的开始。

| 字段 | 唯一写入方 |
|---|---|
| /关系/{键}/Rank·社群点 | 社群脚本（模型只发 <affinity>） |
| /关系/{键}/档案 | 模型（首次登场一次） |
| /五维/* · /时空/* · /日程/* | 日程脚本 |
| /主角/{体力,魔力,伤势} | 对峙/战斗脚本 |
| /事件线索/* · /期限/* · /秘密/* | 剧情脚本 |
| /宫殿/* | 宫殿脚本（前端只写位置与资源） |
| /队伍/* | 战斗脚本 |
| /网/* | 社群脚本 |
| /能力/* | 模型 |

【白名单】只允许写：/主角 /时空 /日程 /五维 /关系 /网 /秘密 /宫殿 /队伍 /能力 /物品与金钱 /守护神 /主角状态 /事件线索 /期限。
不在表里的路径一律丢弃，并在回执里写「已拦截 N 条」。
</单写与白名单>
