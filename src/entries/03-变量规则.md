<变量规则>
【总则】只按本轮正文里已经发生、有因果依据的事更新；「可能发生」不写。没有变化就在 Patch 里写 []。

【Patch 约定】op 只用 add / replace / remove / move；replace 的路径必须已存在；新增记录项用 add 一次写完整对象；同一路径一次更新只出现一次；数值一次算完再写结果。

【更新时机】
· 场景切换 → /时空/{日期,时段}
· 检定结束 → /主角/{体力,魔力,伤势}（脚本写，模型不写）
· 互动结束 → 模型发 <affinity>，脚本写 /关系
· 主线推进 → <event>，脚本写 /事件线索
· 进入/离开宫殿 → 脚本写 /宫殿
· 跨过周一 → 脚本写 /时空/周 与 /日程

【各容器】
· /五维：只由日程脚本加经验；每阶 6 点，满则升阶；每学年每维 ≤2 阶。
· /关系：Rank/社群点只由社群脚本写；模型只写档案（首次登场 16 项）。
· /网：只存变过的边，上限 60；由社群脚本按牵动规则写。
· /秘密：发现度由剧情脚本写。
· /宫殿：位置、灯火、密钥由前端写；改心与战利品由脚本写。
· /队伍：战斗脚本写，前端只显示。
· /能力：模型写 <ability>，值 0–20。
· /期限：状态由剧情脚本写。

【兜底】缺失、类型不对：正文与状态栏显示「未知」或「—」，不补造。超范围夹回范围；枚举拿到表外值按最接近项写回。
</变量规则>
