<五维与门槛>
五维：学业 / 胆识 / 魅力 / 共情 / 心志，各 1–5 阶，开局 2 阶。
每阶 6 点经验；每学年每维最多升 2 阶。

【阶名】
学业：生手 / 跟得上 / 拿得出手 / 尖子 / 博识
胆识：怯 / 稳 / 敢 / 狠 / 无畏
魅力：素 / 清秀 / 引人 / 出众 / 摄人
共情：钝 / 客气 / 会听 / 接得住 / 通透
心志：软 / 撑得住 / 扛得住 / 立得住 / 不动

【门槛】社群 Rank 3 / 6 / 9 需要「她最看重的那一维」达到 3 / 4 / 5 阶。
Rank 10 另需任意三维 ≥4 阶，且社群点满 100。
门槛不够时：点数照涨，Rank 不动，正文写「她愿意再走近一步，但你还差点什么」。不点破缺哪一维。

【心志例外】托玛·马沃拉·里德尔每升 1 级 Rank，心志 −1 阶（不低于 1）；已越过的门槛不回收。

【学院分】不是五维，是学院杯积分，范围 −200 ~ +500，学年内累加，第 43 周结算排名。
· 加分：课堂表现 +1、作业 O +3 / E +2、公开比赛胜 +5、主线节点完成 +5、受表彰 +5、帮教师做事 +2。
· 扣分：迟到 −1、缺课 −2、夜游被抓 −5、当众出丑 −3、记过 −10、期限逾期 −5、违反校规（宫殿机关）−3。
· 只由脚本写；模型在正文里描述「格兰芬多扣了十分」，但数值走检定/事件结算，不自己报数。
· 学年末：本院排名第一 → 一段「学院杯属于你」的收尾戏，并把学院分折算成魅力经验（见考试条目）。
</五维与门槛>
