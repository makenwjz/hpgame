# ===== HP-Reverb · 仓库说明 =====
本仓库是《哈莉·波特·行间》（HP-Reverb）角色卡的全部**设计与运行时代码**。

## 这是什么
- 一张 SillyTavern 角色卡：现实层是周历 / 行动点 / 五维 / 社群 / 关系网 / 涨潮；
  夜间层是 **9 座像素宫殿 + 八方旅人式回合战斗**。
- **121 人可攻略**（三层深度）+ 11 人敌对；22 张塔罗可操作。
